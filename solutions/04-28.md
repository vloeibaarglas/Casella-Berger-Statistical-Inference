**Central idea.** $Y/X$ is standard Cauchy, and $X/(X+Y) = 1/(1+Y/X)$ inherits a Cauchy law; for (b), conditioning on $Y$ and using symmetry gives the same Cauchy density — no surprise, because a symmetric $Y$ satisfies $Y \stackrel{d}{=} S|Y|$.

**Solution.** (a) $T = Y/X \sim \text{Cauchy}(0,1)$. With $W = X/(X+Y) = 1/(1+T)$, $f_W(w) = \frac{1}{\pi(1+((1-w)/w)^2)}\cdot\frac{1}{w^2} = \frac{1/2}{\pi((w-1/2)^2+1/4)}$: $W \sim \text{Cauchy}(1/2,1/2)$.
(b) For $t>0$, $P(X/|Y|\le t) = \mathrm{E}[\Phi(t|Y|)]$, so $f(t) = \mathrm{E}[\phi(t|Y|)|Y|] = \frac{1}{\pi(1+t^2)}$; by symmetry this holds for all $t$: $X/|Y| \sim \text{Cauchy}(0,1)$, the same as $X/Y$.
(c) Not surprising. General theorem: if $X,Y$ are independent and symmetric about $0$ ($X \stackrel{d}{=} -X$, $Y \stackrel{d}{=} -Y$), then $X/|Y| \stackrel{d}{=} X/Y$, since $Y \stackrel{d}{=} S|Y|$ for an independent Rademacher $S$, and $X/(S|Y|) = (XS)/|Y| \stackrel{d}{=} X/|Y|$.
