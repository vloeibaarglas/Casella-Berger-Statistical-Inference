**Central idea.** Bayes' theorem with the warden's tie-breaking rule made explicit; swapping fates transfers C's posterior survival probability to A.

**Solution.** $P(\text{A pardoned}) = P(\text{B}) = P(\text{C}) = 1/3$. Given $W$ = {warden says B dies}: $P(W \mid A) = \gamma$, $P(W \mid B) = 0$ (warden must name C), $P(W \mid C) = 1$ (warden must name B).
(a) $P(W) = \gamma/3 + 0 + 1/3 = (1+\gamma)/3$, so
$$P(A \mid W) = \frac{\gamma/3}{(1+\gamma)/3} = \frac{\gamma}{1+\gamma}.$$
$\frac{\gamma}{1+\gamma} < \frac13 \iff 3\gamma < 1+\gamma \iff \gamma < 1/2$; equal iff $\gamma = 1/2$; greater iff $\gamma > 1/2$.
(b) With $\gamma = 1/2$, $P(W) = 1/2$. Swapping fates with C, A survives iff C was pardoned: $P(C \mid W) = \frac{P(W\mid C)P(C)}{P(W)} = \frac{1/3}{1/2} = 2/3$. (Indeed $P(B \mid W) = 0$, so $P(C \mid W) = 1 - P(A \mid W) = 2/3$.)
