**Central idea.** Random-walk Metropolis needs only the *unnormalized* target density: propose $X^*= X_t + \varepsilon$ ($\varepsilon$ symmetric, e.g., normal), accept with probability $\min(1, \pi(X^*)/\pi(X_t))$; normalizing constants cancel.

**Solution.** In each case run a symmetric random-walk Metropolis chain: at state $x$, propose $x^*= x + z$, $z \sim n(0,\tau^2)$ (tune $\tau$ for $\approx 25$–$40\%$ acceptance); accept (move to $x^*$) with probability $\alpha = \min\!\left(1, \frac{\pi(x^*)}{\pi(x)}\right)$, else stay at $x$. Only ratios of the target $\pi$ are needed:
(a) $\pi(x) \propto \left(1 + \frac{1}{v}\left(\frac{x-\mu}{\sigma}\right)^2\right)^{-(v+1)/2}$ (Student's $t$, location $\mu$, scale $\sigma$); $\alpha = \min\!\left(1, \left[\frac{1+(x^*-\mu)^2/(v\sigma^2)}{1+(x-\mu)^2/(v\sigma^2)}\right]^{-(v+1)/2}\right)$.
(b) $\pi(x) \propto \frac{1}{x}\exp\!\left(-\frac{(\log x-\mu)^2}{2\sigma^2}\right)$, $x > 0$; reject proposals $x^*\leq 0$ (or run the chain on $\log X$ with $\pi_{\log}(y) \propto \exp(-(y-\mu)^2/(2\sigma^2))$ and exponentiate — cleaner, no boundary).
(c) $\pi(x) \propto x^{\alpha-1}\exp(-(x/\beta)^\alpha)$, $x > 0$; again reject $x^*\leq 0$ or work on the log scale.
Discard an initial burn-in (e.g., first few hundred iterates), then take 100 (thinned, if autocorrelation is high) draws as the approximate sample. The chains are valid because the random-walk proposal is symmetric, so detailed balance holds with the stated $\alpha$ (cf. 5.69).
