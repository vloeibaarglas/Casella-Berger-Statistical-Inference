**Central idea.** *Erratum:* as printed, $C^*$ has coverage $\alpha$, not $1-\alpha$ — the cutoff must be $\chi^2_{2n,1-\alpha}$ (and the " $\chi^2_{240,.7} = 251.046$ " in (d) is really $\chi^2_{240,.3}$). With the correction, Madansky's minimum-based interval beats the UMA interval in expected length.

**Solution.** ($\text{exponential}(\lambda)$ = mean $\lambda$, pdf $\lambda^{-1}e^{-x/\lambda}$.) (a) MLR in $-\sum X_i$: UMP size-$\alpha$ test rejects for small $\sum X_i$, i.e. reject iff $2\sum X_i/\lambda_0 < \chi^2_{2n,1-\alpha}$ (lower-$\alpha$ quantile).
(b) *Erratum.* Inverting $A(\lambda_0) = \{2\sum X_i/\lambda_0 \ge \chi^2_{2n,1-\alpha}\}$ gives the UMA interval $\{\lambda : 0 < \lambda \le 2\sum X_i/\chi^2_{2n,1-\alpha}\}$ — with $\chi^2_{2n,1-\alpha}$, not $\chi^2_{2n,\alpha}$ as printed. Proof: as printed, $P_\lambda(\lambda \le 2\sum X_i/\chi^2_{2n,\alpha}) = P(\chi^2_{2n} \ge \chi^2_{2n,\alpha}) = \alpha \ne 1-\alpha$.
(c) $E[\text{Length}] = 2n\lambda/\chi^2_{2n,1-\alpha}$.
(d) With $1-\alpha = .3$: the correct cutoff is $\chi^2_{240,.3} = 251.046$ (the text mislabels it $\chi^2_{240,.7}$; the true upper-$.7$ cutoff is $\approx 228.05$). $E[\text{Length}(C^*)] = 240\lambda/251.046 = .956\lambda$. For $C^M$: $X_{(1)} \sim \text{Exp}(\text{mean }\lambda/n)$, $E[\text{Length}] = \frac{\lambda/n}{-\log .99} = \frac{\lambda}{120(0.0100503)} = .829\lambda < .956\lambda$. Coverage is actually $0.99^{120}=0.2993803913$, slightly below $0.3$. Thus this rounded interval is only approximately a $30\%$ interval. For exact $30\%$ coverage, use $C^M=\{0<\lambda\le X_{(1)}/d\}$ with $d=-\log(0.3)/120=0.01003310670$. Its expected length is $\lambda/[-\log(0.3)]=0.8305835451\lambda$, still shorter than the UMA interval.
