**Central idea.** Maximizing the likelihood is minimizing $\sum|x_i-\theta|$ — the least-absolute-deviations problem, whose solution is any median.
**Solution.** $\log L(\theta\mid\mathbf{x})=-n\log 2-\sum_{i=1}^n|x_i-\theta|$; maximizing $L$ is minimizing $g(\theta)=\sum|x_i-\theta|$. Now $g$ is convex and piecewise linear with slope $g'(\theta)=\#\{x_i<\theta\}-\#\{x_i>\theta\}$ (where defined), which changes sign at any median. Hence: if $n=2m+1$ is odd, the unique minimizer is $\hat\theta=X_{(m+1)}$ (the sample median); if $n=2m$ is even, $g$ is flat on $[X_{(m)},X_{(m+1)}]$, so any $\hat\theta\in[X_{(m)},X_{(m+1)}]$ (e.g. the midpoint) is an MLE.
