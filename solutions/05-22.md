**Central idea.** Differentiate $P(Z^2 \leq t) = P(-\sqrt{t} \leq Z \leq \sqrt{t})$ using $f_Z(z) = 2(1-\Phi(z))\phi(z)$; the $\Phi$ terms telescope to give the $\chi^2_1$ density.

**Solution.** $F_Z(z) = 1 - (1-\Phi(z))^2$, so $f_Z(z) = 2(1-\Phi(z))\phi(z)$. For $t > 0$,
$$P(Z^2 \leq t) = \int_{-\sqrt{t}}^{\sqrt{t}} 2(1-\Phi(z))\phi(z)\,dz,$$
and differentiating (Leibniz rule; the boundary derivatives are $\pm 1/(2\sqrt{t})$):
$$f_{Z^2}(t) = \frac{f_Z(\sqrt{t}) + f_Z(-\sqrt{t})}{2\sqrt{t}} = \frac{\phi(\sqrt{t})}{\sqrt{t}}\big[(1-\Phi(\sqrt{t})) + (1-\Phi(-\sqrt{t}))\big] = \frac{\phi(\sqrt{t})}{\sqrt{t}} = \frac{t^{-1/2}e^{-t/2}}{\sqrt{2\pi}} = \frac{t^{1/2-1}e^{-t/2}}{\Gamma(1/2)2^{1/2}},$$
the $\chi^2_1$ pdf, since $\Phi(\sqrt{t}) + \Phi(-\sqrt{t}) = 1$.
