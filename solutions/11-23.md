**Central idea.** Averaging over blocks leaves $EY_{ij} = \mu+\tau_i$; the $\sum a_i = 0$ condition annihilates the shared block component, leaving only $\sigma^2/r$ per unit weight — which equals $\frac{1}{r}(\sigma^2+\sigma_B^2)(1-\rho)$ since $\rho = \sigma_B^2/(\sigma^2+\sigma_B^2)$.

**Solution.** (a) $Y_{ij} = \mu + \tau_i + B_j + \varepsilon_{ij}$ with $B_j \sim n(0,\sigma_B^2) \perp \varepsilon_{ij} \sim n(0,\sigma^2)$. $EY_{ij} = \mu+\tau_i$; $\mathrm{Var}\,Y_{ij} = \mathrm{Var}(B_j) + \mathrm{Var}(\varepsilon_{ij}) = \sigma_B^2 + \sigma^2$.
(b) $\mathrm{Cov}(Y_{ij},Y_{i'j'}) = \sigma_B^2$ if $j = j'$, $i \neq i'$ (shared block), else 0. So $\mathrm{Cov}(\bar{Y}_{i\cdot},\bar{Y}_{i'\cdot}) = \sigma_B^2/r$ for $i \neq i'$ and $\mathrm{Var}(\bar{Y}_{i\cdot}) = (\sigma_B^2+\sigma^2)/r$. Then
$$\mathrm{Var}\left(\sum a_i\bar{Y}_{i\cdot}\right) = \frac{\sigma^2+\sigma_B^2}{r}\sum a_i^2 + \frac{\sigma_B^2}{r}\sum_{i\neq i'}a_ia_{i'} = \frac{1}{r}\left[\sigma^2\sum a_i^2 + \sigma_B^2\left(\sum a_i\right)^2\right] = \frac{\sigma^2}{r}\sum a_i^2,$$
using $\sum a_i = 0$. Since $\rho = \sigma_B^2/(\sigma^2+\sigma_B^2)$, $(\sigma^2+\sigma_B^2)(1-\rho) = \sigma^2$, giving the stated form.
