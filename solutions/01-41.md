**Central idea.** Bayes' theorem on the channel; for (b), posteriors are proportional to prior × likelihood, computed per two-signal message.

**Solution.** Priors: $P(\text{dot sent}) = 3/7$, $P(\text{dash sent}) = 4/7$. Channel: $P(\text{dash rec} \mid \text{dot sent}) = 1/4$, $P(\text{dot rec} \mid \text{dot sent}) = 3/4$, $P(\text{dot rec} \mid \text{dash sent}) = 1/3$, $P(\text{dash rec} \mid \text{dash sent}) = 2/3$.
(a) $P(\text{dash rec}) = \frac14\cdot\frac37 + \frac23\cdot\frac47 = \frac{41}{84}$. Hence
$$P(\text{dash sent} \mid \text{dash rec}) = \frac{\frac23\cdot\frac47}{41/84} = \frac{32}{41} \approx 0.78.$$
(b) For each sent message $m$, posterior $\propto P(m)\,P(\text{dot-dot rec} \mid m)$:
$$\begin{aligned}
\text{dot-dot:} &\quad (3/7)^2(3/4)^2 = 81/784,\\
\text{dot-dash:} &\quad (3/7)(4/7)(3/4)(1/3) = 48/784,\\
\text{dash-dot:} &\quad (4/7)(3/7)(1/3)(3/4) = 48/784,\\
\text{dash-dash:} &\quad (4/7)^2(1/3)^2 = 16/441.
\end{aligned}$$
Normalizing by $1849/7056$: $P(\text{dot-dot} \mid \text{rec}) = 729/1849$, $P(\text{dot-dash} \mid \text{rec}) = P(\text{dash-dot} \mid \text{rec}) = 432/1849$, $P(\text{dash-dash} \mid \text{rec}) = 256/1849$.
