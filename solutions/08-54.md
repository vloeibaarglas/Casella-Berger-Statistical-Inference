**Central idea.** The conjugate posterior is $\theta \mid \mathbf x \sim n(\mu_n,\sigma_n^2)$; with $z = \sqrt{n}\bar x/\sigma$ the posterior is $\Phi(-z/\sqrt{1+\sigma^2/(n\tau^2)}) \ge \Phi(-z) = p$, with equality as $\tau^2 \to \infty$.

**Solution.** (a) $\theta \mid \mathbf x \sim n(\mu_n,\sigma_n^2)$ with $\sigma_n^2 = (n/\sigma^2+1/\tau^2)^{-1}$, $\mu_n = \frac{n\tau^2}{n\tau^2+\sigma^2}\bar x$. Hence $P(\theta \le 0 \mid \mathbf x) = \Phi(-\mu_n/\sigma_n) = \Phi\left(-z/\sqrt{1+\sigma^2/(n\tau^2)}\right)$, $z = \sqrt{n}\bar x/\sigma$.
(b) $p = \sup_{\theta \le 0} P_\theta(\bar X \ge \bar x) = P_0(\bar X \ge \bar x) = 1-\Phi(z) = \Phi(-z)$.
(c) With $\sigma^2 = \tau^2 = 1$: posterior $= \Phi(-z/\sqrt{1+1/n})$, $p = \Phi(-z)$. For $\bar x > 0$ ($z > 0$), $-z/\sqrt{1+1/n} > -z$, and $\Phi$ increasing, so posterior $> p$ always.
(d) As $\tau^2 \to \infty$, $\sqrt{1+\sigma^2/(n\tau^2)} \to 1$, so $P(\theta \le 0 \mid \mathbf x) \to \Phi(-z) = p$: with a diffuse prior the one-sided posterior equals the p-value — no Lindley paradox here.
