**Central idea.** Apply the ratio criterion (Theorem 6.2.13): the likelihood ratio is $\theta$-free exactly on the level sets of the minimal sufficient statistic.

**Solution.** (a) $\frac{f(\mathbf{x}\mid\theta)}{f(\mathbf{y}\mid\theta)} = \exp\big(\theta(\sum x_i-\sum y_i) - \tfrac12(\sum x_i^2-\sum y_i^2)\big)$, constant in $\theta$ iff $\sum x_i = \sum y_i$. Minimal sufficient: $\sum X_i$ (or $\bar{X}$).
(b) $\frac{f(\mathbf{x}\mid\theta)}{f(\mathbf{y}\mid\theta)} = e^{-\sum(x_i-y_i)}\frac{I(\theta < x_{(1)})}{I(\theta < y_{(1)})}$, constant in $\theta$ iff $x_{(1)} = y_{(1)}$ (otherwise the ratio jumps between $0$ and a nonzero value as $\theta$ crosses the minima). Minimal sufficient: $X_{(1)}$.
(c) $\log\frac{f(\mathbf{x}\mid\theta)}{f(\mathbf{y}\mid\theta)} = -\sum(x_i-y_i) + 2\sum_i\big[\log(1+e^{\theta-y_i}) - \log(1+e^{\theta-x_i})\big]$. If the ratio is $\theta$-free, differentiating and expanding $\sigma(\theta-c) = 1 - e^{-(\theta-c)} + O(e^{-2(\theta-c)})$ as $\theta\to\infty$ gives $\sum e^{kx_i} = \sum e^{ky_i}$ for all $k \ge 1$, whence $\{e^{x_i}\}$ and $\{e^{y_i}\}$ have the same power sums and are the same multiset. Conversely equal multisets give ratio $1$. Minimal sufficient: the order statistics $(X_{(1)},\ldots,X_{(n)})$.
(d) $\frac{f(\mathbf{x}\mid\theta)}{f(\mathbf{y}\mid\theta)} = \prod_{i=1}^n \frac{1+(y_i-\theta)^2}{1+(x_i-\theta)^2}$. If constant ($=c$) for all $\theta$, then $\prod_i((\theta-y_i)^2+1) = c\prod_i((\theta-x_i)^2+1)$ as polynomials; leading coefficients force $c = 1$, and unique factorization over $\mathbb{C}$ (roots $y_i \pm i$, $x_i \pm i$) forces $\{x_i\} = \{y_i\}$ as multisets. Minimal sufficient: the order statistics.
(e) $\log\frac{f(\mathbf{x}\mid\theta)}{f(\mathbf{y}\mid\theta)} = \sum|y_i-\theta| - \sum|x_i-\theta|$, piecewise linear in $\theta$ with slope jumping by $2$ at each data point. If constant for all $\theta$, the slope $-\#\{x_i>\theta\}+\#\{x_i<\theta\}+\#\{y_i>\theta\}-\#\{y_i<\theta\} \equiv 0$, so the empirical distributions agree at all continuity points: same multiset. Minimal sufficient: the order statistics.
