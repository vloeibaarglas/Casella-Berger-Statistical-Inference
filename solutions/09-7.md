**Central idea.** Profile out the nuisance parameter $\theta$: the LRT compares the constrained MLE $\tilde\theta(a_0)$ with the unconstrained MLE, and the confidence set is the $a_0$-slice of the likelihood-ratio acceptance region.

**Solution.** (a) $\ell(\theta,a) = -\frac{n}{2}\log(a\theta) - \sum(x_i-\theta)^2/(2a\theta)$. For fixed $a$, the constrained MLE is the positive root of $n\theta^2 + na\theta - \sum x_i^2 = 0$,
$$\tilde\theta(a) = \frac{-a + \sqrt{a^2 + 4\overline{x^2}}}{2}, \qquad \overline{x^2} = \frac1n\sum x_i^2.$$
The $1-\alpha$ set is $C(x) = \{a_0 : L(\tilde\theta(a_0),a_0)/L(\hat\theta,\hat a) \ge k_\alpha\}$ (asymptotically $-2\log\text{ratio} \le \chi^2_{1,\alpha}$).
(b) $\ell(\theta,a) = -n\log\theta - \frac{n}{2}\log a - \sum(x_i-\theta)^2/(2a\theta^2)$; the constrained MLE is the positive root of $na\theta^2 + n\bar x\,\theta - \sum x_i^2 = 0$,
$$\tilde\theta(a) = \frac{-\bar x + \sqrt{\bar x^2 + 4a\,\overline{x^2}}}{2a},$$
and $C(x)$ has the same profile-LRT form as in (a).
