**Central idea.** Location shifts add $a$ to $\bar{x}+k$ (matching $\theta\mapsto\theta+a$), but a scale change multiplies the stray constant $k$ while the induced parameter map sends $\theta\mapsto c\theta+a$ — the $k$ breaks equivariance unless it vanishes.

**Solution.** (a) $\mathcal{G}_2$ induces $\bar\theta = \theta+a$ on the parameter. $W(g_a(\mathbf{x})) = \bar{x}+a+k = W(\mathbf{x})+a$: equivariant. $\mathcal{G}_1$ induces $\bar\theta = c\theta+a$: $W(g_{a,c}(\mathbf{x})) = c\bar{x}+a+k$, whereas equivariance requires $cW(\mathbf{x})+a = c\bar{x}+ck+a$; these agree iff $ck = k$, i.e. $c = 1$, and with $k\ne 0$ they differ for $c\ne 1$. Not equivariant under $\mathcal{G}_1$.
(b) For $\mathcal{G}_1$-equivariant $W$ ($W(c\mathbf{x}+a\mathbf{1}) = cW(\mathbf{x})+a$): with $X_i = \sigma Z_i+\theta$, $\mathrm{E}_{\theta,\sigma}[W] = \theta + \sigma\,\mathrm{E}_{0,1}[W(\mathbf{Z})]$, unbiased for all $(\theta,\sigma)$ iff $\mathrm{E}_{0,1}[W(\mathbf{Z})] = 0$. For $\mathcal{G}_2$-equivariant $W$ ($W(\mathbf{x}+a\mathbf{1}) = W(\mathbf{x})+a$): $\mathrm{E}_{\theta,\sigma}[W] = \theta + \mathrm{E}_{0,\sigma}[W(\sigma\mathbf{Z})]$, unbiased for all $(\theta,\sigma)$ iff $\mathrm{E}_{0,\sigma}[W] = 0$ for every $\sigma > 0$ (location $0$).
