**Central idea.** Translate the words into set operations, then use additivity on disjoint pieces (inclusion–exclusion).

**Solution.** (a) $A \cup B$: $P(A) + P(B) - P(A \cap B)$. (b) Symmetric difference $A \,\Delta\, B = (A \setminus B) \cup (B \setminus A)$, disjoint: $[P(A) - P(A\cap B)] + [P(B) - P(A\cap B)] = P(A) + P(B) - 2P(A \cap B)$. (c) Same as (a): $P(A) + P(B) - P(A \cap B)$. (d) Complement of $A \cap B$: $1 - P(A \cap B)$.
