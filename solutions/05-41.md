**Central idea.** Convergence in probability to $\mu$ is convergence in distribution to the degenerate law at $\mu$; both directions are inclusions of the relevant events.

**Solution.** (a) ($\Rightarrow$) Let $x > \mu$, $\varepsilon = x - \mu > 0$: $\{|X_n-\mu| \leq \varepsilon\} = \{\mu-\varepsilon \leq X_n \leq \mu+\varepsilon\} \subseteq \{X_n \leq x\}$, so $P(X_n \leq x) \geq P(|X_n-\mu| \leq \varepsilon) \to 1$. Let $x < \mu$, $\varepsilon = \mu - x > 0$: $\{X_n \leq x\} \subseteq \{|X_n-\mu| \geq \varepsilon\}$, so $P(X_n \leq x) \leq P(|X_n-\mu| \geq \varepsilon) \to 0$.
(b) ($\Leftarrow$) $\{|X_n-\mu| > \varepsilon\} = \{X_n < \mu-\varepsilon\} \cup \{X_n > \mu+\varepsilon\} \subseteq \{X_n \leq \mu-\varepsilon\} \cup \{X_n > \mu+\varepsilon\}$. Hence $P(|X_n-\mu| > \varepsilon) \leq P(X_n \leq \mu-\varepsilon) + 1 - P(X_n \leq \mu+\varepsilon) \to 0 + 1 - 1 = 0$, using the assumed cdf convergence at $\mu-\varepsilon < \mu$ and $\mu+\varepsilon \geq \mu$.
