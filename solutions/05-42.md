**Central idea.** $P(X_{(n)} \leq x) = F(x)^n$; choose the scaling so that $n(1-F(\text{threshold}))$ tends to a constant, and $(1-c/n)^n \to e^{-c}$ produces the extreme-value limit.

**Solution.** (a) For Beta$(1,\beta)$, $F(x) = 1-(1-x)^\beta$ on $(0,1)$. For $t > 0$,
$$P(n^v(1-X_{(n)}) \leq t) = 1 - P\!\left(X_{(n)} < 1-\tfrac{t}{n^v}\right) = 1 - \left[1-\left(\tfrac{t}{n^v}\right)^\beta\right]^n = 1 - \left[1-\frac{t^\beta}{n^{v\beta}}\right]^n.$$
With $v = 1/\beta$, this is $1 - (1-t^\beta/n)^n \to 1 - e^{-t^\beta}$, a Weibull cdf. So $v = 1/\beta$ works.
(b) For exponential$(1)$, $P(X_{(n)} - a_n \leq t) = (1-e^{-(t+a_n)})^n$. With $a_n = \log n$,
$$\left(1-\frac{e^{-t}}{n}\right)^n \to e^{-e^{-t}},$$
the Gumbel cdf. So $a_n = \log n$ works (the classic exponential-maximum normalization).
