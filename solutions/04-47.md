**Central idea.** $Z = |X|\,\mathrm{sign}(Y) \stackrel{d}{=} S|X| \stackrel{d}{=} X$ since $X$ is symmetric; but $ZY = |X||Y| > 0$ a.s., whereas a nondegenerate bivariate normal charges all four quadrants.

**Solution.** (a) $Z = X\cdot\mathrm{sign}(XY) = |X|\cdot\mathrm{sign}(Y)$. $\mathrm{sign}(Y) = \pm1$ with probability $1/2$ each, independent of $|X|$, so $Z \stackrel{d}{=} S|X| \stackrel{d}{=} X \sim n(0,1)$.
(b) $ZY = |X||Y| > 0$ a.s.: $Z$ and $Y$ always have the same sign. If $(Z,Y)$ were bivariate normal and nondegenerate, each open quadrant would have positive probability; it is degenerate only if $|{\rm Corr}| = 1$, but ${\rm Corr}(Z,Y) = \mathrm{E}[ZY] = (\mathrm{E}|X|)^2 = 2/\pi \notin \{-1,1\}$. Hence $(Z,Y)$ is not bivariate normal.
