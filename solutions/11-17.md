**Central idea.** Protection works because a false difference assertion requires the $F$ gate to open first, and the $F$ test has level $\alpha$ under the global null; without the gate, $\binom{k}{2}$ chances at error $\alpha$ each inflate the familywise rate.

**Solution.** (a) Under the global null (all means equal), a false assertion of difference can only occur if the pairwise $t$ tests are performed, which requires the $F$ test to reject. Hence
$$P(\text{false assertion}\mid H_0) \leq P(F\text{ rejects}\mid H_0) = \alpha,$$
regardless of $k$.
(b) Without the $F$ gate, under $H_0$ each of the $m = \binom{k}{2}$ pairwise $t$ tests falsely rejects with probability $\alpha$, so $P(\text{at least one false}\mid H_0) = P(\bigcup_{pairs}\{\text{reject}\})$, which can be as large as $\min(1, m\alpha)$ — exceeding $\alpha$ for $k \geq 3$ (e.g. approaching $1-(1-\alpha)^m$ for nearly independent tests). Each single comparison still has $P(\text{false difference}) = \alpha$: the comparisonwise rate.
(c) Fish toxin data ($n = (4,6,5,4)$, $N = 19$, $k = 4$): $\bar y = (23.0, 32.83, 21.0, 13.0)$, $S_p^2 = 12.72$, $F = 26.09$ on $(3,15)$ df — significant at $\alpha = 0.05$ (indeed $p \approx 4\times10^{-6}$), so proceed. With $t_{15,0.025} = 2.13$:

| Pair | $|t|$ | Significant? |
|---|---|---|
| Toxin 1 – Toxin 2 | 4.27 | yes |
| Toxin 1 – Toxin 3 | 0.84 | no |
| Toxin 1 – Control | 3.96 | yes |
| Toxin 2 – Toxin 3 | 5.48 | yes |
| Toxin 2 – Control | 8.61 | yes |
| Toxin 3 – Control | 3.34 | yes |

Conclusions: Toxin 2 produces the most liver deterioration (mean 32.8), the control the least (13.0); Toxins 1 and 3 are indistinguishable (23.0 vs 21.0); every other pair differs significantly.
