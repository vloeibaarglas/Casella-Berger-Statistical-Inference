**Central idea.** Write the log-likelihood ratio as a function of $\mu$ (resp. $(\mu,\sigma^2)$) and read off which sums must match for it to be parameter-free; in $n(\mu,\mu)$ the $\sum x_i$ terms cancel, leaving only $\sum x_i^2$.

**Solution.** Put $A = \sum x_i^2-\sum y_i^2$, $B = \sum x_i-\sum y_i$.
(a)–(b) For $n(\mu,\mu)$: $\log\frac{f(\mathbf{x}\mid\mu)}{f(\mathbf{y}\mid\mu)} = -\frac{A}{2\mu} + B$, constant in $\mu > 0$ iff $A = 0$ ($B$ is already $\mu$-free). By Theorem 6.2.13, $\sum X_i^2$ is minimal sufficient. $(\sum X_i,\sum X_i^2)$ is sufficient by Theorem 6.2.10 but not minimal, since $\sum X_i^2$ is sufficient and $(\sum X_i,\sum X_i^2)$ is not a function of $\sum X_i^2$ alone.
(c) For $n(\mu,\mu^2)$ ($\mu \ne 0$): $\log\frac{f(\mathbf{x}\mid\mu)}{f(\mathbf{y}\mid\mu)} = -\frac{A}{2\mu^2} + \frac{B}{\mu}$, constant in $\mu$ iff $A = B = 0$ (multiply by $2\mu^2$: $-A + 2B\mu$ constant forces $A = B = 0$). Minimal sufficient: $(\sum X_i,\sum X_i^2)$.
(d) For $n(\mu,\sigma^2)$: $\log\frac{f(\mathbf{x}\mid\mu,\sigma^2)}{f(\mathbf{y}\mid\mu,\sigma^2)} = -\frac{A}{2\sigma^2} + \frac{\mu B}{\sigma^2}$, constant on the open set $\Re\times(0,\infty)$ iff $A = B = 0$ (vary $\mu$ at fixed $\sigma^2$ to get $B = 0$, then $A = 0$). Minimal sufficient: $(\sum X_i,\sum X_i^2)$.
