**Central idea.** (a) is induction via convolution; $\{N = n\} = \{S_{n-1} \leq 1\} \setminus \{S_n \leq 1\}$ since partial sums increase; then $E[N] = \sum_{n \geq 0}P(N > n) = \sum 1/n! = e$.

**Solution.** (a) For $0 \leq t \leq 1$: $P(S_1 \leq t) = t$, and $P(S_k \leq t) = \int_0^t P(S_{k-1} \leq t-u)\,du = \int_0^t \frac{(t-u)^{k-1}}{(k-1)!}\,du = \frac{t^k}{k!}$ by induction.
(b) $\{N = n\} = \{S_{n-1} \leq 1 < S_n\} = \{S_{n-1} \leq 1\} \setminus \{S_n \leq 1\}$ (since $S_n \geq S_{n-1}$, $\{S_n \leq 1\} \subseteq \{S_{n-1} \leq 1\}$), so $P(N = n) = P(S_{n-1} \leq 1) - P(S_n \leq 1) = \frac{1}{(n-1)!} - \frac{1}{n!}$ (with $P(N=1) = 0$ since $S_1 = U_1 \leq 1$ a.s.). For a positive integer variable, $E[N] = \sum_{n \geq 0}P(N > n) = \sum_{n \geq 0}P(S_n \leq 1) = \sum_{n=0}^{\infty}\frac{1}{n!} = e$.
(c) Simulate: repeatedly generate uniforms until their sum exceeds 1, record $N$; the average of many $N$'s estimates $e \approx 2.71828$.
(d) $\mathrm{Var}(N) = E[N^2] - e^2$ with $E[N^2] = \sum_{n \geq 0}(2n+1)P(N > n) = \sum_{n \geq 0}\frac{2n+1}{n!} = 3e$, so $\mathrm{Var}(N) = e(3-e) \approx 0.766$. For the mean of $n$ replicates, $1.96\sqrt{\mathrm{Var}(N)/n} \leq 0.0005$ (four digits = $\pm 0.0005$) gives $n \geq \left(\frac{1.96\sqrt{0.766}}{0.0005}\right)^2 \approx 1.18\times10^7$ — about 12 million replications.
