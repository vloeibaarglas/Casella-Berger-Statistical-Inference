**Central idea.** (a) Profiling out the scale $\lambda$ leaves a monotone profile in the location $\theta$, so the LRT rejects for large $\min X_i/\bar X$. (b) Profiling out $\beta$ gives a closed-form profile likelihood in $\gamma$ alone; the LRT has no closed-form critical region and is computed numerically.

**Solution.** (a) With $m = \min x_i$, $L(\theta,\lambda) = \lambda^{-n}\exp(-\sum(x_i-\theta)/\lambda)\,I(\theta \le m)$. For fixed $\theta \le m$, $\hat\lambda(\theta) = \bar x - \theta$, and the profile log-likelihood $\ell_p(\theta) = -n\log(\bar x-\theta) - n$ is strictly increasing in $\theta$. Under $H_0$ the maximizer is $\hat\theta_0 = \min(0,m)$; unconstrained it is $\hat\theta = m$. Thus
$$\lambda(\mathbf x) = \begin{cases} \left(\dfrac{\bar x - m}{\bar x}\right)^n, & m \ge 0, \\ 1, & m < 0,\end{cases}$$
so the LRT rejects iff $T(\mathbf x) = m/\bar x \ge c'$ (the $m<0$ case is consistent since then $T < 0 < c'$). The cutoff $c'$ is set from $\sup_{\theta\le0}P_{\theta,\lambda}(T \ge c') = \alpha$; at $\theta = 0$, $T = \min E_i/\bar E$ for iid standard exponentials $E_i$, free of $\lambda$.
(b) The Weibull pdf is $f(x\mid\gamma,\beta) = \frac{\gamma}{\beta}(x/\beta)^{\gamma-1}\exp(-(x/\beta)^\gamma)$, $x>0$. $\ell(\gamma,\beta) = n\log\gamma - n\gamma\log\beta + (\gamma-1)\sum\log x_i - \sum(x_i/\beta)^\gamma$. For fixed $\gamma$, $\hat\beta(\gamma)^\gamma = \frac1n\sum x_i^\gamma$, giving the profile $\ell_p(\gamma) = n\log\gamma - n\log(\frac1n\sum x_i^\gamma) + (\gamma-1)\sum\log x_i - n$. Under $H_0$ ($\gamma=1$), $\hat\beta = \bar x$ and $\ell_p(1) = -n\log\bar x - n$. Hence
$$\lambda(\mathbf x) = \frac{L(1,\bar x)}{\sup_{\gamma,\beta}L(\gamma,\beta)}, \qquad -2\log\lambda = 2\bigl[\sup_\gamma \ell_p(\gamma) - \ell_p(1)\bigr],$$
and the LRT rejects for large $-2\log\lambda$. The supremum over $\gamma$ has no closed form (it solves $n/\gamma - n\log\hat\beta(\gamma) + \sum\log x_i - \sum (x_i/\hat\beta(\gamma))^\gamma\log(x_i/\hat\beta(\gamma)) = 0$), so in practice the statistic is maximized numerically; asymptotically $-2\log\lambda \approx \chi^2_1$ under $H_0$.
