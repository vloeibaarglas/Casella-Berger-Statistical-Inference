**Central idea.** Induction on $n$, using the two-set laws as the base case.

**Solution.** Claim: $(\cup_{i=1}^n A_i)^c = \cap_{i=1}^n A_i^c$ and $(\cap_{i=1}^n A_i)^c = \cup_{i=1}^n A_i^c$. For $n = 2$ this is Problem 1.3(c). Assume true for $n$; then $(\cup_{i=1}^{n+1} A_i)^c = \big((\cup_{i=1}^n A_i) \cup A_{n+1}\big)^c = (\cup_{i=1}^n A_i)^c \cap A_{n+1}^c = (\cap_{i=1}^n A_i^c) \cap A_{n+1}^c = \cap_{i=1}^{n+1} A_i^c$, using the $n=2$ law and the induction hypothesis. The second law is dual.
