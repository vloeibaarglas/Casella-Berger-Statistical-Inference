**Central idea.** (a) Each one-sided piece has probability $< \alpha/2$ except at its own endpoint, so the supremum over $[\theta_1,\theta_2]$ is $< \alpha$. (b) $|\bar X-\bar\theta|/\sqrt{S^2/n} = |t_{n-1}(\delta)|$ is stochastically increasing in $|\delta|$, so the null rejection probability is maximized at the endpoints. (c) Conditioning on $S$ reduces everything to normal CDFs; a calculus lemma gives monotonicity.

**Solution.** Write $c = t_{n-1,\alpha/2}$, $SE = \sqrt{S^2/n}$.
(a) $P_\theta(\bar X > \theta_2 + c\cdot SE)$ is increasing in $\theta$ (conditional on $S$ it is $1-\Phi(\cdot)$, increasing in $\theta$), equal to $\alpha/2$ at $\theta = \theta_2$; similarly $P_\theta(\bar X < \theta_1 - c\cdot SE) \le \alpha/2$ with equality only at $\theta_1$. Hence for every $\theta \in [\theta_1,\theta_2]$, $P_\theta(\text{reject}) < \alpha/2 + \alpha/2 = \alpha$ (at $\theta_2$ the second term is $< \alpha/2$ by stochastic ordering; likewise at $\theta_1$). So $\sup_{H_0} P_\theta < \alpha$: not size $\alpha$ (it is conservative).
(b) $P_\theta(|\bar X-\bar\theta| > k\cdot SE) = P(|t_{n-1}(\delta)| > k)$ with $\delta = \sqrt{n}(\theta-\bar\theta)/\sigma$. By the MLR, $|t_{n-1}(\delta)|$ is stochastically increasing in $|\delta|$, so on $[\theta_1,\theta_2]$ this is maximized at the endpoints $|\delta| = \sqrt{n}(\theta_2-\theta_1)/(2\sigma)$. Since $P(|t_{n-1}(\delta_0)| > k)$ decreases continuously from $1$ to $0$ in $k$, there is a unique $k$ with $P(|t_{n-1}(\sqrt{n}(\theta_2-\theta_1)/(2\sigma))| > k) = \alpha$: size $\alpha$.
(c) For (b): if $\theta > \theta_2$, then $|\delta| > \sqrt{n}(\theta_2-\theta_1)/(2\sigma)$, so $P_\theta = P(|t_{n-1}(\delta)| > k) \ge \alpha$ (MLR); similarly for $\theta < \theta_1$. Unbiased. For (a): let $s_a = \sup_{H_0} P_\theta < \alpha$. Conditional on $S = s\sigma$, $P_\theta(\text{reject}) = E_s[h(a)]$ where $a = \sqrt{n}(\theta_2-\theta)/\sigma$, $k_0 = \sqrt{n}(\theta_2-\theta_1)/\sigma$, $h(a) = 1-\Phi(a/s+c)+\Phi((a-k_0)/s-c)$. Now $h'(a) = \frac1s[\phi((a-k_0)/s-c)-\phi(a/s+c)]$, and $|(a-k_0)/s-c|^2-|a/s+c|^2 = (k_0/s+2c)(k_0-2a)/s$, so $h'(a) < 0$ for $a < k_0/2$. For $\theta > \theta_2$, $a < 0 < k_0/2$, so $h$ is strictly decreasing in $a$, i.e. $P_\theta$ strictly increasing in $\theta$; thus $P_\theta > P_{\theta_2}$ for $\theta > \theta_2$. On $(\bar\theta,\theta_2)$, $a \in (0,k_0/2)$, $h'(a) < 0$, $da/d\theta < 0$, so $P_\theta$ is strictly increasing there; by symmetry about $\bar\theta$, $\max_{[\theta_1,\theta_2]} P_\theta = P_{\theta_1} = P_{\theta_2} = s_a$. Hence $P_\theta > s_a$ for $\theta > \theta_2$, and symmetrically for $\theta < \theta_1$: unbiased of size $s_a$.
