**Central idea.** Match the sample space to the type of measurement: finite sequences for repeated trials, integers for counts, intervals for continuous measurements.

**Solution.** (a) $S = \{(x_1,x_2,x_3,x_4) : x_i \in \{H,T\}\}$, $2^4 = 16$ outcomes. (b) $S = \{0, 1, 2, \dots\}$. (c) $S = \{t : t \geq 0\}$ (hours). (d) $S = \{w : w > 0\}$ (grams, say; a vector in $(0,\infty)^n$ if $n$ rats are weighed). (e) $S = \{p : 0 \leq p \leq 1\}$.
