**Central idea.** A test that always rejects has rejection probability 1 under every parameter value — hence true size 1 and power 1; always accepting gives size 0 and power 0.

**Solution.** (a) $\phi \equiv 1$: size $= \sup_{\Theta_0} E_\theta\phi = 1$, power $\gamma(\theta) = 1$ for all $\theta \in \Theta_1$. True Type I error probability $1$, Type II error probability $0$. Choosing $\alpha$ after the fact to force rejection does not produce a level-$\alpha$ test — it produces a size-1 test masquerading as one.
(b) $\phi \equiv 0$: size $= 0$, power $\equiv 0$. True Type I error probability $0$, Type II error probability $1$: $H_0$ is never rejected even when blatantly false.
