**Central idea.** The $\mathbf{a}_i$ form a Helmert hierarchy peeling off one treatment at a time, so sequential tests pin down the ordering; orthogonality is $\sum a_ib_i/n_i = 0$ (Exercise 11.11). The fertilizer contrasts each isolate one nutrient (K, Mg dose, Mg level, Zn) against a shared reference, a scientifically natural set.

**Solution.** (a) With equal $n_i = n$: $\mathbf{a}_1$ compares the control $\theta_1$ to the average of the four new treatments; $\mathbf{a}_2$ compares $\theta_2$ to the average of $\theta_3,\theta_4,\theta_5$; $\mathbf{a}_3$ compares $\theta_3$ to the average of $\theta_4,\theta_5$; $\mathbf{a}_4$ compares $\theta_4$ to $\theta_5$. Testing them in order hierarchically determines the ranking: e.g. a significant $\mathbf{a}_1$ test says the control differs from the new-treatment average (with the sign saying which is larger); then $\mathbf{a}_2$ locates $\theta_2$ relative to the remaining three; $\mathbf{a}_3$ locates $\theta_3$ relative to $\theta_4,\theta_5$; $\mathbf{a}_4$ orders $\theta_4$ vs $\theta_5$. Together the four tests can establish a complete ordering such as $\theta_1 < \bar\theta_{\text{new}}$, $\theta_2 > \mathrm{avg}(\theta_3,\theta_4,\theta_5)$, etc.
(b) By 11.11, $\mathrm{Cov}(\sum a_i\bar{Y}_{i\cdot},\sum b_i\bar{Y}_{i\cdot}) = \sigma^2\sum a_ib_i/n_i = (\sigma^2/n)\,\mathbf{a}\cdot\mathbf{b}$ with equal $n_i$. Directly: $\mathbf{a}_1\!\cdot\!\mathbf{a}_2 = -\frac14 + 3(\frac14\cdot\frac13) = 0$; $\mathbf{a}_1\!\cdot\!\mathbf{a}_3 = -\frac14 + 2(\frac14\cdot\frac12) = 0$; $\mathbf{a}_1\!\cdot\!\mathbf{a}_4 = -\frac14+\frac14 = 0$; $\mathbf{a}_2\!\cdot\!\mathbf{a}_3 = -\frac13 + 2(\frac13\cdot\frac12) = 0$; $\mathbf{a}_2\!\cdot\!\mathbf{a}_4 = -\frac13+\frac13 = 0$; $\mathbf{a}_3\!\cdot\!\mathbf{a}_4 = -\frac12+\frac12 = 0$. All dot products are 0, so all pairs are uncorrelated.
(c) With equal $n$, $\mathbf{a}_1\!\cdot\!\mathbf{a}_2 = (1)(-1) = -1 \neq 0$, so they are not orthogonal (similarly $\mathbf{a}_2\!\cdot\!\mathbf{a}_4 = 1 \neq 0$). Treatments (Mg, K, Zn): 1=$(0,0,0)$, 2=$(0,200,0)$, 3=$(50,200,0)$, 4=$(200,200,0)$, 5=$(0,200,200)$. $\mathbf{a}_1$: treatment 2 vs 1 = potassium effect; $\mathbf{a}_2$: avg(3,4) vs 2 = magnesium effect at fixed K; $\mathbf{a}_3$: 3 vs 4 = magnesium dose effect; $\mathbf{a}_4$: 5 vs 2 = zinc effect. Each contrast isolates exactly one nutrient question using treatment 2 as the common reference — scientifically sensible despite non-orthogonality.
