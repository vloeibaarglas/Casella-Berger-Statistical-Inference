**Central idea.** (a) $E[T'] = E[X]\,E[(Y/\nu)^{-1/2}]$ by independence; the $\chi^2$ negative moment is a gamma integral. (c) Write the pdf as a normal variance-mixture and apply Karlin's composition theorem: the normal location kernel is TP2, and the mixing kernel is TP2 because $\log w(e^x)$ is concave.

**Solution.** (a) $E[T'] = E[X]\,E[(Y/\nu)^{-1/2}] = \mu\sqrt{\nu}\,E[Y^{-1/2}]$. For $Y \sim \chi^2_\nu$, $E[Y^{-1/2}] = \frac{\Gamma((\nu-1)/2)}{\sqrt{2}\,\Gamma(\nu/2)}$ ($\nu > 1$). Hence (with $\delta^2 = \mu^2$)
$$E[T'] = \mu\sqrt{\frac{\nu}{2}}\,\frac{\Gamma((\nu-1)/2)}{\Gamma(\nu/2)} \quad (\nu > 1),$$
which is $0$ if $\mu = 0$. Also $E[T'^2] = E[X^2]E[\nu/Y] = (1+\mu^2)\frac{\nu}{\nu-2}$ ($\nu > 2$), so
$$\mathrm{Var}(T') = \frac{\nu(1+\delta^2)}{\nu-2} - \delta^2\frac{\nu}{2}\left[\frac{\Gamma((\nu-1)/2)}{\Gamma(\nu/2)}\right]^2 \quad (\nu > 2).$$
(b) If $\delta = 0$, $(\delta t)^k$ is $1$ for $k = 0$ and $0$ for $k \ge 1$, so only $k = 0$ survives: $f_{T'}(t \mid 0) = \frac{\Gamma((\nu+1)/2)}{\Gamma(1/2)\Gamma(\nu/2)\sqrt{\nu}(1+t^2/\nu)^{(\nu+1)/2}}$, the central $t_\nu$ pdf.
(c) Use the signed noncentrality $\delta=\mu$. If restricting to $\mu\ge0$, this agrees with $\sqrt{\mu^2}$; for negative means, the sign cannot be discarded since the distribution is reflected. Conditional on $Y = y$, $T' \sim n(\delta/\sqrt{y/\nu}, 1/(y/\nu))$, so with $u = \sqrt{y/\nu}$,
$$f(t \mid \delta) = \int_0^\infty \phi(tu-\delta)\,w(u)\,du, \quad w(u) = 2\nu u^2 f_{\chi^2_\nu}(\nu u^2) = \frac{2(\nu/2)^{\nu/2}}{\Gamma(\nu/2)}u^\nu e^{-\nu u^2/2}.$$
For $t > 0$, $s = tu$ gives $f(t \mid \delta) = \int_0^\infty \phi(s-\delta)K_+(t,s)\,ds$ with $K_+(t,s) = \frac1t w(s/t)\mathbf 1_{s>0}$. Now $\phi(s-\delta)$ is TP2 in $(s,\delta)$ (normal location MLR), and $K_+$ is TP2 in $(t,s)$ on $(0,\infty)^2$: for $t_2 > t_1 > 0$, $s_2 > s_1 > 0$,
$$\frac{K_+(t_2,s_2)K_+(t_1,s_1)}{K_+(t_2,s_1)K_+(t_1,s_2)} = \frac{w(a)w(b)}{w(c)w(d)} \ge 1,$$
where $a = s_2/t_2$, $b = s_1/t_1$, $c = s_1/t_2$, $d = s_2/t_1$ satisfy $ab = cd$, $c < \min(a,b)$, $d > \max(a,b)$; with $h(x) = \log w(e^x) = C + \nu x - \frac\nu2 e^{2x}$ and $h''(x) = -2\nu e^{2x} < 0$, concavity of $h$ gives $h(\log a) + h(\log b) \ge h(\log c) + h(\log d)$. By Karlin's basic composition formula, $f$ is TP2 in $(t,\delta)$ for $t > 0$. For $t < 0$, $s = tu$ gives $f(t \mid \delta) = \int_{-\infty}^0 \phi(s-\delta)K_-(t,s)\,ds$, $K_-(t,s) = \frac1{|t|}w(s/t)\mathbf 1_{s<0}$, TP2 on $(-\infty,0)^2$ by the same concavity (now with $c > \max(a,b)$, $d < \min(a,b)$). Hence $R(t) = f(t \mid \delta_2)/f(t \mid \delta_1)$ ($\delta_2 > \delta_1$) is increasing on each half-line; $R$ is continuous, so for $t_1 < 0 < t_2$, $R(t_1) \le R(0) \le R(t_2)$. Thus MLR in $\delta$ on $\mathbb R$.
