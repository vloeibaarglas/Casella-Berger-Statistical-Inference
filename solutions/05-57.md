**Central idea.** The shared $X_3$ is the only source of dependence: it contributes $\mathrm{Var}(X_3) = \lambda_3$ to the covariance, and $\{Z_1 = Z_2 = 1\} = \{X_1 = X_2 = X_3 = 0\}$. The correlation bound follows from $e^{\lambda_3}-1 \leq e^{\lambda_i+\lambda_3}-1 = (1-p_i)/p_i$.

**Solution.** (a) $\mathrm{Cov}(Y_1,Y_2) = \mathrm{Cov}(X_1+X_3, X_2+X_3) = \mathrm{Var}(X_3) = \lambda_3$ (all cross terms vanish by independence).
(b) $Y_i \sim \text{Poisson}(\lambda_i+\lambda_3)$, so $Z_i = \mathbf{1}_{\{Y_i=0\}} \sim \text{Bernoulli}(p_i)$ with $p_i = e^{-(\lambda_i+\lambda_3)}$. Now $P(Z_1 = Z_2 = 1) = P(Y_1 = Y_2 = 0) = P(X_1 = X_2 = X_3 = 0) = e^{-(\lambda_1+\lambda_2+\lambda_3)} = p_1p_2e^{\lambda_3}$. Hence
$$\mathrm{Corr}(Z_1,Z_2) = \frac{p_1p_2e^{\lambda_3} - p_1p_2}{\sqrt{p_1(1-p_1)p_2(1-p_2)}} = \frac{p_1p_2(e^{\lambda_3}-1)}{\sqrt{p_1(1-p_1)}\sqrt{p_2(1-p_2)}} \geq 0.$$
(c) $\mathrm{Corr}(Z_1,Z_2) = \sqrt{\frac{p_1p_2}{(1-p_1)(1-p_2)}}\,(e^{\lambda_3}-1)$. Since $\lambda_1 \geq 0$, $e^{\lambda_3}-1 \leq e^{\lambda_1+\lambda_3}-1 = \frac{1-p_1}{p_1}$, giving $\mathrm{Corr} \leq \sqrt{\frac{p_1p_2}{(1-p_1)(1-p_2)}}\cdot\frac{1-p_1}{p_1} = \sqrt{\frac{p_2(1-p_1)}{p_1(1-p_2)}}$; symmetrically using $\lambda_2 \geq 0$ gives the other bound. So the correlation lies in $[0, \min\{\cdot\}]$ — always nonnegative and bounded away from 1 unless the $p_i$ match.
