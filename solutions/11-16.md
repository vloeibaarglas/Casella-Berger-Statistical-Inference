**Central idea.** Equality of all means is the intersection of all pairwise equalities; the union–intersection principle then rejects the global null when any pairwise $t$ test rejects.

**Solution.** (a) $\theta_1 = \cdots = \theta_k$ holds iff every pair is equal, i.e. iff $\theta_i - \theta_j = 0$ for all $i,j$; negating, some pair differs iff not all are equal.
(b) $H_0: \boldsymbol{\theta} \in \bigcap_{i,j}\Theta_{ij}$ and $H_1: \boldsymbol{\theta} \in \bigcup_{i,j}\Theta_{ij}^c$. This is exactly the union–intersection form $H_0 = \bigcap_\gamma \Theta_{0\gamma}$ vs $H_1 = \bigcup_\gamma \Theta_{1\gamma}$. The UIT rejects $H_0$ iff at least one component test rejects: for each pair $(i,j)$, run the two-sample $t$ test of $\theta_i = \theta_j$, $|\bar{Y}_{i\cdot}-\bar{Y}_{j\cdot}|/(S_p\sqrt{1/n_i+1/n_j}) > t_{N-k,\alpha/2}$, and reject the ANOVA $H_0$ if any pair rejects. Multiplicity is handled as in Miscellanea 11.5.2 (e.g. Bonferroni or Tukey adjustment) to control the experimentwise error.
