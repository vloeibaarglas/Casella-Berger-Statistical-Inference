**Central idea.** Neyman–Pearson logic: include $t$ iff its "length cost" $g(t)$ is small relative to its "probability value" $f(t)$.

**Solution.** (a) For any $C'$ with $\int_{C'}f \ge 1-\alpha = \int_C f$:
$$\int_{C'}g - \int_C g = \int_{C'\setminus C}g - \int_{C\setminus C'}g \ge \lambda\!\int_{C'\setminus C}\!f - \lambda\!\int_{C\setminus C'}\!f = \lambda\left(\int_{C'}f - \int_C f\right) \ge 0,$$
using $g \ge \lambda f$ off $C$ and $g < \lambda f$ on $C$. So $C = \{g < \lambda f\}$ minimizes length.
(b) 9.37: length $Y(1/a-1/b) = Y\int_a^b t^{-2}dt$, so $g(t) = t^{-2}$, $f(t) = nt^{n-1}$ on $[0,1]$. $C = \{t^{-2} < \lambda nt^{n-1}\} = \{t > c\}$: $C = (c,1]$, $1-c^n = 1-\alpha$, $c = \alpha^{1/n}$ — the interval $[Y, Y/\alpha^{1/n}]$. 9.42: length $x\int_a^b t^{-2}dt$, $g(t) = t^{-2}$, $f = \text{gamma}(k,1)$ pdf; $C = \{t : t^{-2} < \lambda f(t)\}$ is an interval $[a,b]$ (unimodality) with $1/a^2 = \lambda f(a)$, $1/b^2 = \lambda f(b) \iff f(a)a^2 = f(b)b^2$, as in 9.42(a).
