**Central idea.** All four are "minimize something subject to $\int_a^b f_{n-1} = 1-\alpha$"; the Lagrange conditions collapse to $f_{n+k}(a) = f_{n+k}(b)$ for $k = 2, 3, 1$ because $t^m f_{n-1}(t) \propto f_{n-1+2m}(t)$.

**Solution.** Write $W = (n-1)S^2/\sigma_0^2 \sim \chi^2_{n-1}$.
(a) $-2\log\lambda = W - n\log W + n\log n - n \equiv g(W)$; $\{g(W) \le c\} = [a,b]$ with $g(a) = g(b) \iff a - n\log a = b - n\log b \iff a^{n/2}e^{-a/2} = b^{n/2}e^{-b/2} \iff f_{n+2}(a) = f_{n+2}(b)$.
(b) Minimize $(n-1)s^2(1/a-1/b)$ s.t. $\int_a^b f_{n-1} = 1-\alpha$: Lagrange gives $1/a^2 = \lambda f_{n-1}(a)$, $1/b^2 = \lambda f_{n-1}(b)$, i.e. $a^2f_{n-1}(a) = b^2f_{n-1}(b) \iff f_{n+3}(a) = f_{n+3}(b)$.
(c) False coverage $h(t) = P(a/t \le \chi^2_{n-1} \le b/t)$ ($t = \sigma^2/\sigma_0^2$); unbiasedness $\Rightarrow h'(1) = 0 \iff af_{n-1}(a) = bf_{n-1}(b) \iff f_{n+1}(a) = f_{n+1}(b)$. Minimizing the endpoint ratio $b/a$ s.t. coverage gives the same FOC.
(d) By definition of equal tails.
(e) $n=3$ ($\chi^2_2$), $\alpha=.1$ (lengths $\times (n-1)s^2$): (a) LRT: $a=.2065$, $b=12.5214$, length $4.76$; (b) minimum-length: $a=.2104$, $b=18.0077$, length $4.70$; (c) shortest-unbiased: $a=.1676$, $b=7.8643$, length $5.84$; (d) equal-tail: $a=.1026$, $b=5.9915$, length $9.58$. So the order is minimum-length $<$ LRT $<$ shortest-unbiased $<$ equal-tail; the equal-tail interval is the longest of the four.
