**Central idea.** $P(Y/\theta \le u) = u^n$ is free of $\theta$; among $[Y/b,Y/a]$ with $b^n-a^n = 1-\alpha$, the length $Y(1/a-1/b)$ decreases in $a$, forcing $a^n = \alpha$, $b = 1$.

**Solution.** $P_\theta(Y/\theta \le u) = P_\theta(Y \le u\theta) = u^n$, $0 \le u \le 1$: pivotal. A pivotal interval is $[Y/b,Y/a]$ with $P(a \le Q \le b) = b^n-a^n = 1-\alpha$, length $Y(1/a-1/b)$. With $b = (a^n+1-\alpha)^{1/n}$, $\frac{d}{da}(1/a-1/b) = -1/a^2 + a^{n-1}/b^{\,n+1} < 0$ (since $a < b$), so length decreases in $a$; max feasible $a = \alpha^{1/n}$ ($b=1$). Shortest: $[Y,\ Y/\alpha^{1/n}]$.
