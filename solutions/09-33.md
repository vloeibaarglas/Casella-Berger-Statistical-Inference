**Central idea.** For $\mu \ne 0$ only one side of $C_a(x)$ binds, reducing coverage to a one-sided normal tail $\Phi(1.645) = .95$; under the flat prior the posterior is $n(x,1)$ and the credible probability interpolates between $.90$ (symmetric case) and $.95$.

**Solution.** (a) For $\mu > 0$: $\min\{0,X-a\} \le 0 < \mu$ always, so $\mu \in C_a \iff \mu \le \max\{0,X+a\} \iff X \ge \mu-a$: probability $\Phi(a) = .95$. For $\mu < 0$: $\max\{0,X+a\} \ge 0 > \mu$ always, so $\mu \in C_a \iff \min\{0,X-a\} \le \mu \iff X \le \mu+a$: probability $\Phi(a) = .95$. For $\mu = 0$: $0 \in C_a(x)$ always, coverage $1$.
(b) $\mu\mid x \sim n(x,1)$. For $|x| \le a$: $C_a(x) = [x-a,x+a]$, credible probability $P(|Z| \le a) = 2\Phi(1.645)-1 = .90$. For $x > a$: $C_a(x) = [0,x+a]$, probability $\Phi(a) - \Phi(-x) = .95 - \Phi(-x)$, increasing from $.90$ to $.95$ as $x\to\infty$; symmetrically for $x < -a$.
