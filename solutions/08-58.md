**Central idea.** With $c_I = 8$, $c_{II} = 3$ in (8.3.12), $\max_\theta R(\theta,\alpha) = \max(8\alpha, 3(1-\alpha))$; the minimax $\alpha$ equalizes the two.

**Solution.** Example 8.3.31 tests $H_0: \theta \ge \theta_0$ vs $H_1: \theta < \theta_0$ with $X \sim n(\theta,1)$ under loss (8.3.12) with $c_I = 8$ (Type I), $c_{II} = 3$ (Type II). For the test rejecting $\{X < \theta_0-z_\alpha\}$: on $H_0$ ($\theta \ge \theta_0$), $R(\theta,\alpha) = 8P_\theta(X < \theta_0-z_\alpha) = 8\Phi(-z_\alpha-(\theta-\theta_0))$, decreasing in $\theta$, maximized at $\theta = \theta_0$ with value $8\Phi(-z_\alpha) = 8\alpha$; on $H_1$ ($\theta < \theta_0$), $R(\theta,\alpha) = 3P_\theta(X \ge \theta_0-z_\alpha) = 3\Phi(z_\alpha+(\theta-\theta_0))$, increasing in $\theta$, with supremum $3\Phi(z_\alpha) = 3(1-\alpha)$ as $\theta \uparrow \theta_0$. Hence $\max_\theta R(\theta,\alpha) = \max(8\alpha,\,3(1-\alpha))$, minimized when $8\alpha = 3(1-\alpha)$, i.e. $\alpha = 3/11 \approx .273$ (minimax value $24/11 \approx 2.18$).
