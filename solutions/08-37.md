**Central idea.** The (profile) likelihood ratio is $1$ for $\bar X \le \theta_0$ and strictly decreasing in $\bar X$ for $\bar X > \theta_0$; MLR in $\bar X$ plus Karlin–Rubin gives UMP. With $\sigma^2$ unknown the same computation yields the one-sided $t$-test.

**Solution.** (a) $P_\theta(\bar X > \theta_0 + z_\alpha\sigma/\sqrt{n}) = 1 - \Phi(z_\alpha - \sqrt{n}(\theta-\theta_0)/\sigma) \le \alpha$ for $\theta \le \theta_0$, equality at $\theta_0$: size $\alpha$. LRT: $\lambda(\mathbf x) = \sup_{\theta \le \theta_0}L(\theta)/\sup_\theta L(\theta)$; $L$ is maximized at $\bar X$ unconstrained and at $\min(\bar X,\theta_0)$ under $H_0$, so $\lambda = 1$ if $\bar X \le \theta_0$ and $\lambda = \exp(-n(\bar X-\theta_0)^2/2\sigma^2)$ if $\bar X > \theta_0$. Thus $\{\lambda < c\} = \{\bar X > \theta_0 + c'\}$: the LRT.
(b) $n(\theta,\sigma^2)$ has MLR in $\bar X$; Karlin–Rubin says $\{\bar X > c\}$ is UMP level $\alpha$ (with $c = \theta_0 + z_\alpha\sigma/\sqrt{n}$).
(c) At $\theta = \theta_0$, $\sqrt{n}(\bar X-\theta_0)/S \sim t_{n-1}$; for $\theta < \theta_0$ the rejection probability is $P(t_{n-1}(\delta) > t_{n-1,\alpha}) < \alpha$ ($\delta < 0$), so size $\alpha$. LRT: maximizing first over $\sigma^2$ ($\hat\sigma^2_\theta = \frac1n\sum(X_i-\theta)^2$) then over $\theta \le \theta_0$ gives numerator $\frac1n\sum(X_i-\bar X)^2$ if $\bar X \le \theta_0$, $\frac1n\sum(X_i-\theta_0)^2$ if $\bar X > \theta_0$; denominator $\frac1n\sum(X_i-\bar X)^2$. Hence $\lambda = 1$ if $\bar X \le \theta_0$ and $\lambda = \left(\frac{\sum(X_i-\bar X)^2}{\sum(X_i-\theta_0)^2}\right)^{n/2}$ if $\bar X > \theta_0$. Since $\frac{\sum(X_i-\theta_0)^2}{\sum(X_i-\bar X)^2} = 1 + \frac{n(\bar X-\theta_0)^2}{(n-1)S^2}$ is strictly increasing in $\bar X$ for $\bar X > \theta_0$, $\{\lambda < c\} = \{\sqrt{n}(\bar X-\theta_0)/S > c'\}$: the one-sided $t$-test.
