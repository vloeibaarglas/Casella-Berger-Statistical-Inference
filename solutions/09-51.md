**Central idea.** $\bar X - \theta$ is pivotal in a location family, so the coverage event depends on $\theta$ only through $\bar X - \theta$.

**Solution.** $P_\theta(\theta \in C) = P_\theta(\bar x - k_1 \le \theta \le \bar x + k_2) = P_\theta(-k_2 \le \bar X - \theta \le k_1)$. Since $\bar X - \theta$ has pdf $f_{\bar X}(\cdot)$ free of $\theta$, this equals $\int_{-k_2}^{k_1} f_{\bar X}(t)\,dt$, independent of $\theta$.
