**Central idea.** Under $H_0$, $\sqrt{n}(\bar X-\theta_0)/S \sim t_{n-1}$; the LRT reduces to a monotone function of $|\bar X-\theta_0|/S$.

**Solution.** (a) Under $\theta_0$, $T = \sqrt{n}(\bar X-\theta_0)/S \sim t_{n-1}$, so $P_{\theta_0}(|T| > t_{n-1,\alpha/2}) = \alpha$: size $\alpha$ (point null).
(b) $\lambda(\mathbf x) = \sup_{\sigma^2}L(\theta_0,\sigma^2)/\sup_{\theta,\sigma^2}L(\theta,\sigma^2) = \left(\frac{\sum(X_i-\bar X)^2}{\sum(X_i-\theta_0)^2}\right)^{n/2}$, since $\hat\sigma^2 = \frac1n\sum(X_i-\theta)^2$ in each case. Then $\{\lambda < c\} = \left\{\frac{\sum(X_i-\theta_0)^2}{\sum(X_i-\bar X)^2} > c'\right\} = \left\{\frac{n(\bar X-\theta_0)^2}{(n-1)S^2} > c''\right\} = \{|T| > c'''\}$: the two-sided $t$-test (with $c''' = t_{n-1,\alpha/2}$ for size $\alpha$).
