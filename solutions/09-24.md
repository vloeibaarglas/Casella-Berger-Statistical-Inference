**Central idea.** The endpoints $L(x), U(x)$ are increasing in $x$, so $\{x : L(x) \le \lambda \le U(x)\}$ is a contiguous block of integers — and it changes only when $\lambda$ crosses an endpoint.

**Solution.** The first display is just $P_\lambda(\lambda \in [L(X),U(X)]) = \sum_x P_\lambda(X=x)$ over $x$ with $L(x)\le\lambda\le U(x)$. Since $L(x) = \chi^2_{2x,1-\alpha/2}/2$ and $U(x) = \chi^2_{2(x+1),\alpha/2}/2$ are strictly increasing in $x$, $\{x:L(x)\le\lambda\} = \{x \ge x_l(\lambda)\}$ and $\{x:U(x)\ge\lambda\} = \{x \le x_u(\lambda)\}$; intersecting gives the contiguous sum. As $\lambda$ increases, the block $[x_l(\lambda),x_u(\lambda)]$ changes only when $\lambda$ passes some $L(x)$ or $U(x)$ — hence the coverage is a step function with jumps exactly at the interval endpoints.
