**Central idea.** Binomial = sum of Bernoulli trials; hypergeometric = sequential draws without replacement using conditional success probabilities; negative binomial = Bernoulli trials until the 5th success (or a sum of 5 geometrics).

**Solution.** (a) For $i = 1,\ldots,8$: generate $U_i \sim$ uniform$(0,1)$, set $B_i = \mathbf{1}_{\{U_i < 2/3\}}$; return $Y = \sum_{i=1}^8 B_i$.
(b) Sequential sampling without replacement: set $r = 8$ (successes remaining), $t = 10$ (draws remaining), $Y = 0$; for $j = 1,\ldots,4$: generate $U \sim$ uniform$(0,1)$; if $U < r/t$ then $Y \gets Y+1$, $r \gets r-1$; $t \gets t-1$. Return $Y$.
(c) Repeat Bernoulli$(1/3)$ trials (success if $U < 1/3$) until 5 successes occur; return the number of failures. Equivalently, return $\sum_{i=1}^{5}\big\lfloor \frac{\log U_i}{\log(2/3)}\big\rfloor$ (sum of 5 iid geometric$(1/3)$ "failures-before-success" variables, generated by inversion).
