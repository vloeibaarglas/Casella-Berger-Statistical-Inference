**Central idea.** All are one-line consequences of $P(X \mid Y) = P(X \cap Y)/P(Y)$ plus basic set algebra.

**Solution.** (a) $P(A \cap B) = P(A) - P(A \cap B^c) \geq P(A) - P(B^c) = P(A)$, so $P(A \cap B) = P(A)$ and $P(A \mid B) = P(A)/1$. (b) $A \subset B$ gives $A \cap B = A$: $P(B \mid A) = P(A)/P(A) = 1$ and $P(A \mid B) = P(A)/P(B)$. (c) Disjointness gives $A \cap (A \cup B) = A$ and $P(A \cup B) = P(A)+P(B)$. (d) Chain: $P(A \cap B \cap C) = \frac{P(A\cap B\cap C)}{P(B\cap C)}\cdot\frac{P(B\cap C)}{P(C)}\cdot P(C)$.
