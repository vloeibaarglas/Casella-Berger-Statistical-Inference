**Central idea.** Write the NB mgf as $\left[1-\frac{r(1-p)}{rp}(e^t-1)\right]^{-r}$ and use $(1+a_r/r)^{-r}\to e^{-a}$.

**Solution.** $M_Y(t) = \left(\frac{p}{1-(1-p)e^t}\right)^r = \left[1-\frac{1-p}{p}(e^t-1)\right]^{-r}$ for $t < -\log(1-p)$. Since $r(1-p)\to\lambda$ and $p\to1$, $\frac{r(1-p)}{p}(e^t-1)\to\lambda(e^t-1)$, so
$$M_Y(t) = \left[1-\frac{\lambda(e^t-1)+o(1)}{r}\right]^{-r} \longrightarrow \exp\big(\lambda(e^t-1)\big),$$
the Poisson$(\lambda)$ mgf, for each fixed $t$.
