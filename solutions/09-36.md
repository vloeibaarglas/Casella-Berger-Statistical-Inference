**Central idea.** $T - \theta \sim \text{Exp}(\text{rate } n(n+1)/2)$ is supported on $[0,\infty)$, so the shortest interval $[T+a,T+b]$ pushes $b$ to $0$ and puts all the probability at the left.

**Solution.** Joint pdf $= \exp(\theta\sum i - \sum x_i)\prod_i I_{[i\theta,\infty)}(x_i) = e^{-\sum x_i}e^{\theta n(n+1)/2}I_{[ \theta,\infty)}(T)$; by factorization $T$ is sufficient. $P(T > t) = \prod_i e^{i\theta - it} = e^{-(t-\theta)n(n+1)/2}$ ($t > \theta$), so $W = T-\theta \sim \text{Exp}(m)$, $m = n(n+1)/2$. $P(\theta \in [T+a,T+b]) = P(-b \le W \le -a) = P(0 \le W \le -a)$ (needs $a \le 0 \le b$) $= 1-e^{ma}$; length $b-a$ is minimized at $b = 0$, $a = (\log\alpha)/m$. Shortest: $[T + (\log\alpha)/m,\ T]$, length $-\log(\alpha)/m$.
