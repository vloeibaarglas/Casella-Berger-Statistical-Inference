**Central idea.** Only the signs $P(X_i \lessgtr m) = 1/2$ matter (binomial); prediction uses symmetry of ranks among $n+1$ iid variables; tolerance uses $U_i = F(X_i) \sim U(0,1)$.

**Solution.** (a) $P(m \le X_{(n)}) = 1-P(\text{all }X_i < m) = 1-(1/2)^n$; similarly $P(m \ge X_{(1)}) = 1-(1/2)^n$; $P(X_{(1)} \le m \le X_{(n)}) = 1 - 2(1/2)^n$ (equalities for continuous $F$).
(b) Among $n+1$ iid (continuous) variables all rank orders are equally likely: $P(X_{n+1} \le X_{(n)}) = n/(n+1)$, $P(X_{(1)} \le X_{n+1} \le X_{(n)}) = (n-1)/(n+1)$.
(c) With continuous $F$, $U_i = F(X_i)$ iid $U(0,1)$. One-sided: $P(F(X_{(n)}) \ge p) = 1-P(\text{all }U_i < p) = 1-p^n$. Two-sided: $P(U_{(n)}-U_{(1)} \ge p) = 1 - \iint_{v-u<p}n(n-1)(v-u)^{n-2}dudv = 1 - [np^{n-1}-(n-1)p^n] = 1-p^n-n(1-p)p^{n-1}$.
