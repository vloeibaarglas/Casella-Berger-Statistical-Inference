**Central idea.** (a) MLR in $\bar X$ plus Karlin–Rubin. (b) A UMP test would have to be simultaneously most powerful against $\theta_1 > \theta_0$ and $\theta_2 < \theta_0$, but the Neyman–Pearson tests for these point in opposite directions — impossible since $\bar X$ has full support.

**Solution.** (a) The $n(\theta,1)$ family has MLR in $\bar X$. By Karlin–Rubin the UMP level-$\alpha$ test of $\theta \ge \theta_0$ versus $\theta < \theta_0$ rejects for small $\bar X$: $\bar X < \theta_0 - z_\alpha/\sqrt{n}$ (size exactly $\alpha$ since $\bar X$ is continuous).
(b) Suppose $\phi^*$ were UMP level $\alpha$. Fix $\theta_1 > \theta_0$ and $\theta_2 < \theta_0$; then $\phi^*$ is MP level $\alpha$ for each point alternative. The likelihood ratio $f(\mathbf x \mid \theta_1)/f(\mathbf x \mid \theta_0)$ is strictly increasing in $\bar X$, so by Neyman–Pearson (a.e. uniqueness, and $P(\bar X = c) = 0$) $\phi^*= \mathbf 1_{\{\bar X > c_1\}}$ a.s.; likewise $\phi^*= \mathbf 1_{\{\bar X < c_2\}}$ a.s. Hence $\mathbf 1_{\{\bar X > c_1\}} = \mathbf 1_{\{\bar X < c_2\}}$ a.s. But under $\theta_0$, $\bar X \sim n(\theta_0, 1/n)$ has support all of $\mathbb R$: if $c_1 < c_2$, they differ on $\{\bar X > c_2\}$ (positive probability); if $c_1 \ge c_2$, they differ on $\{\bar X < c_2\}$ (positive probability). Contradiction. Hence no UMP test exists.
