**Central idea.** Theorem 6.6.5 says the likelihood-ratio vector for a finite subfamily with common support is minimal sufficient for that subfamily; if it is 1–1 with the candidate statistic and the candidate is sufficient for the whole family, minimality lifts. (For (c) the common-support hypothesis fails, so the ratio criterion Theorem 6.2.13 — the engine behind 6.6.5, cf. Exercise 6.28 — is used directly; for (d)–(e) ratios at enough generic parameter values determine the order statistics, so 6.6.5 applies directly.)

**Solution.** (a) Take $f_0,f_1$ to be the joint $n(0,1)$ and $n(1,1)$ densities (common support $\Re^n$). $\frac{f_1(\mathbf{x})}{f_0(\mathbf{x})} = \exp(n(\bar{x}-\tfrac12))$, 1–1 in $\bar{x}$. $\bar{X}$ is sufficient for $\{n(\theta,1)\}$, so by Theorem 6.6.5(b) the ratio — hence $\bar{X}$ — is minimal sufficient.
(b) Take $f_0,f_1$ to be the joint $\text{gamma}(\alpha,1)$ and $\text{gamma}(\alpha,2)$ densities (common support $(0,\infty)^n$). $\frac{f_1(\mathbf{x})}{f_0(\mathbf{x})} = 2^{-n\alpha}e^{\sum x_i/2}$, 1–1 in $\sum x_i$. $\sum X_i$ is sufficient (Theorem 6.2.10), so by Theorem 6.6.5(b) it is minimal sufficient.
(c) The $\text{uniform}(0,\theta)$ family has nested, not common, supports, so Theorem 6.6.5 does not apply directly; use Theorem 6.2.13 instead. Here $\frac{f(\mathbf{x}\mid\theta)}{f(\mathbf{y}\mid\theta)} = \frac{I(x_{(n)} < \theta)}{I(y_{(n)} < \theta)}$: on $\theta > \max(x_{(n)},y_{(n)})$ both densities equal $\theta^{-n}$ and the ratio is $1$, but as a function of $\theta$ the ratio is constant iff $x_{(n)} = y_{(n)}$ (if $x_{(n)} < y_{(n)}$, the ratio is $0$ for $\theta \in (x_{(n)},y_{(n)}]$ but $1$ beyond — not constant). Hence $\max X_i = X_{(n)}$ is minimal sufficient.
(d) For Cauchy$(\theta,1)$, $\frac{f(\mathbf{x}\mid\theta)}{f(\mathbf{y}\mid\theta)} = \prod_i\frac{1+(y_i-\theta)^2}{1+(x_i-\theta)^2}$; constancy in $\theta \in \Re$ forces $\prod_i((\theta-y_i)^2+1) \equiv \prod_i((\theta-x_i)^2+1)$ as polynomials, and unique factorization (roots $x_i\pm i$) gives identical multisets (Exercise 6.9(d)). Evaluating the ratio at $2n$ generic $\theta$ values determines this degree-$2n$ polynomial, hence the multiset: the finite ratio vector is 1–1 with the order statistics, which are sufficient (joint density symmetric), so by Theorem 6.6.5 they are minimal sufficient.
(e) For $\text{logistic}(\mu,\beta)$ the same argument as Exercise 6.9(c) (with $\theta = \mu$) shows ratios at $n$ generic $\mu$ values determine the multiset; the order statistics are sufficient and hence minimal sufficient by Theorem 6.6.5.
