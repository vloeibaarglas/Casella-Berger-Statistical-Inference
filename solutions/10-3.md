**Central idea.** The log-likelihood derivative factors as $n(W-\theta-\theta^2)/(2\theta^2)$; only the positive root is admissible, and the approximate variance is $1/(nI(\theta))$.

**Solution.** (a) With $S(\theta)=\sum(x_i-\theta)^2 = nW-2n\theta\bar x+n\theta^2$,
$$l(\theta) = -\tfrac n2\log\theta - \frac{S(\theta)}{2\theta} + c,\qquad \frac{dl}{d\theta} = -\frac{n}{2\theta} + \frac{n(W-\theta^2)}{2\theta^2} = \frac{n\,(W-\theta-\theta^2)}{2\theta^2}.$$
Setting this to zero gives $\theta^2+\theta-W = 0$, with roots $\frac{-1\pm\sqrt{1+4W}}{2}$. Since $W>0$ a.s. and $\theta>0$, the MLE is the positive root
$$\hat\theta = \frac{-1+\sqrt{1+4W}}{2}$$
(the negative root is $<0$; $l\to-\infty$ as $\theta\downarrow 0$ or $\theta\to\infty$, so this critical point is the global maximizer).
(b) From $l'(\theta) = n(W-\theta-\theta^2)/(2\theta^2)$,
$$l''(\theta) = \frac n2\cdot\frac{(-\theta-2\theta^2)\theta-2(W-\theta-\theta^2)\theta}{\theta^4}\cdot\theta = \frac n2\cdot\frac{-\theta-2\theta^2-2(W-\theta-\theta^2)}{\theta^3}.$$
Since $E_\theta W = \theta+\theta^2$, $E_\theta l''(\theta) = \frac n2\cdot\frac{-\theta-2\theta^2}{\theta^3} = -\frac{n(1+2\theta)}{2\theta^2}$, so $I(\theta) = \frac{1+2\theta}{2\theta^2}$ and
$$\mathrm{Var}(\hat\theta)\approx \frac{1}{nI(\hat\theta)} = \frac{2\hat\theta^2}{n(2\hat\theta+1)}.$$
(The delta method applied to $W$, using $\hat\theta = g(W)$ with $g(w)=(-1+\sqrt{1+4w})/2$, gives the same value.)
