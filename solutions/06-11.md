**Central idea.** All five are location families, so writing $X_i = Z_i + \theta$ makes the $\theta$ cancel in every difference; independence then hinges on whether the minimal sufficient statistic is complete (Basu) or already contains the $Y_i$.

**Solution.** (a) Each pdf in 6.9 has the form $f_0(x-\theta)$. Write $X_i = Z_i + \theta$ with $Z_i$ iid from $f_0$ (free of $\theta$). Then $Y_i = X_{(n)}-X_{(i)} = (Z_{(n)}+\theta)-(Z_{(i)}+\theta) = Z_{(n)}-Z_{(i)}$, whose distribution does not involve $\theta$. Hence $(Y_1,\ldots,Y_{n-1})$ is ancillary. General theorem (as in Example 6.2.18): in a location family, any statistic invariant under simultaneous translation $x_i \mapsto x_i + c$ (in particular any function of the differences $X_i - X_j$) is ancillary.
(b) (a) Normal: minimal sufficient $\bar{X}$ is complete sufficient, $(Y_i)$ ancillary $\Rightarrow$ independent by Basu's Theorem. (b) Location exponential: minimal sufficient $X_{(1)}$ is complete sufficient (Exercise 6.30(a)), $(Y_i)$ ancillary $\Rightarrow$ independent by Basu. (c) Logistic, (d) Cauchy, (e) double exponential: the minimal sufficient statistic is the full set of order statistics, of which $(Y_1,\ldots,Y_{n-1})$ is a (nontrivial) function — so they are not independent (indeed $Y_{n-1} = X_{(n)}-X_{(n-1)}$ is determined by the minimal sufficient statistic).
