**Central idea.** Inverting a UMP test's acceptance region yields a UMA confidence set; MLR gives the test direction (large $Y = \sum X_i$ for Poisson; small $x$ for logistic with $H_1: \theta < \theta_0$).

**Solution.** (a) $Y = \sum X_i \sim \text{Poisson}(n\lambda)$ has MLR; UMP level-$\alpha$ test rejects for large $Y$. $A(\lambda_0) = \{Y \le c(\lambda_0)\}$ (with randomization); since $c(\lambda_0)$ increases in $\lambda_0$, $C(y) = \{\lambda_0 : y \in A(\lambda_0)\} = [\underline{\lambda}(y),\ \infty)$ where $\underline{\lambda}(y)$ solves $P_{\underline{\lambda}}(Y \ge y) = \alpha$. Via $P_\lambda(Y \ge y) = P(\chi^2_{2y} \le 2n\lambda)$: $C(y) = [\chi^2_{2y,1-\alpha}/(2n),\ \infty)$, UMA (a lower confidence bound, as befits a one-sided test against $\lambda > \lambda_0$).
(b) The logistic location family is log-concave, hence MLR; the UMP test of $H_0:\theta=\theta_0$ vs $H_1:\theta<\theta_0$ rejects for small $x$: $A(\theta_0) = \{x > \theta_0 + c_0\}$ with $P_0(X \le c_0) = \alpha$. Inverting, $C(x) = \{\theta_0 : \theta_0 < x - c_0\} = (-\infty,\ x - c_0]$, UMA. For standard logistic $F(t) = 1/(1+e^{-t})$, $c_0 = \log(\alpha/(1-\alpha))$, so $U(x) = x + \log((1-\alpha)/\alpha)$.
