**Central idea.** The log-likelihood is linear in $(\alpha,\beta)$ with coefficients $(\sum Y^*_j,\sum Y^*_jx^*_j)$ — factorization is immediate; the Hessian involves only the fitted probabilities, so observed and expected information coincide.

**Solution.** (a) $L(\alpha,\beta)=\prod_j F_j^{Y^*_j}(1-F_j)^{n_j-Y^*_j}$ with $F_j=e^{\alpha+\beta x^*_j}/(1+e^{\alpha+\beta x^*_j})$. Then
$$\log L=\alpha\sum_jY^*_j+\beta\sum_jY^*_jx^*_j-\sum_j n_j\log(1+e^{\alpha+\beta x^*_j}),$$
so by the Factorization Theorem, $(\sum_jY^*_j,\sum_jY^*_jx^*_j)$ is sufficient for $(\alpha,\beta)$.

(b) From the score $\partial\log L/\partial\alpha=\sum_j(Y^*_j-n_jF_j)$: $\partial^2\log L/\partial\alpha^2=-\sum_jn_jF_j(1-F_j)$, $\partial^2\log L/\partial\alpha\partial\beta=-\sum_jx^*_jn_jF_j(1-F_j)$, $\partial^2\log L/\partial\beta^2=-\sum_j(x^*_j)^2n_jF_j(1-F_j)$, using $dF_j/d(\alpha+\beta x^*_j)=F_j(1-F_j)$. None of these involve $Y^*_j$, so the observed information equals the expected information, giving (12.3.10).
