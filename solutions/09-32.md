**Central idea.** With prior $\theta \sim n(\mu,\tau^2)$, write $\gamma = \sigma^2/(n\tau^2)$; both the coverage of the Bayes set and the credibility of the classical set reduce to normal probabilities over $Z$-intervals whose centers drift to $\pm\infty$ in the unfavorable regimes.

**Solution.** From Example 9.2.18, $\delta^B(\bar x) = w\mu + (1-w)\bar x$, $\text{Var}(\theta\mid\bar x) = \sigma^2\tau^2/(\sigma^2+n\tau^2)$, $w = \sigma^2/(\sigma^2+n\tau^2)$; put $\gamma = \sigma^2/(n\tau^2) = w/(1-w)$.
(a) $\theta - \delta^B(\bar X) = w(\theta-\mu) - (1-w)\frac{\sigma}{\sqrt n}Z$. Dividing $|\theta-\delta^B| \le z_{\alpha/2}\sqrt{\text{Var}}$ by $(1-w)\sigma/\sqrt n$ and using $\sqrt{\text{Var}}/[(1-w)\sigma/\sqrt n] = \sqrt{1+\gamma}$ gives the stated $Z$-interval.
(b) With $\tau = \sigma/\sqrt n$, $\gamma = 1$; the interval is $[-\sqrt2\,z_{\alpha/2} + (\theta-\mu)/(\sigma/\sqrt n),\ \sqrt2\,z_{\alpha/2} + (\theta-\mu)/(\sigma/\sqrt n)]$. For fixed $\theta\ne\mu$, as $\sigma^2/n\to0$ both endpoints $\to +\infty$ or both $\to -\infty$, so the probability $\to 0$: not a $1-\alpha$ confidence set.
(c) If $\theta = \mu$, the probability is $P(|Z| \le \sqrt{1+\gamma}\,z_{\alpha/2}) = 2\Phi(\sqrt{1+\gamma}\,z_{\alpha/2})-1$, increasing in $\gamma \in (0,\infty)$ from $1-\alpha$ (as $\gamma\to0$) to $1$ (as $\gamma\to\infty$): bounded away from zero, min $1-\alpha$, max $1$.
(d) Under the posterior, $(\theta-\delta^B(\bar x))/\sqrt{\text{Var}} \sim n(0,1)$; writing $\theta-\bar x = (\theta-\delta^B) - w(\bar x-\mu)$ and dividing by $\sqrt{\text{Var}}$ gives the stated form (using $w/\sqrt{\text{Var}} = \gamma/(\sqrt{1+\gamma}\,\sigma/\sqrt n)$). As $|\bar x|\to\infty$ the shift $\to\pm\infty$, so the probability $\to 0$: not bounded away from zero, hence the classical set is not a $1-\alpha$ credible set.
