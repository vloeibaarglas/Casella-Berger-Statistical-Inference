**Central idea.** This is the normal–inverse-gamma conjugate family; the marginal posterior of $\theta$ is a $t$ with $2a+n$ df — never $n-1$ — so the classical $t_{n-1}$ set cannot be recovered exactly.

**Solution.** (a) $n(\theta\mid\mu,\sigma^2/\kappa_0)$ with $\kappa_0 = 1/\tau^2$ times $IG(a,b)$ is the normal–inverse-gamma family, conjugate for $(\theta,\sigma^2)$: the posterior is $N$-$IG(\mu_n,\kappa_n,a_n,b_n)$ with $\kappa_n = \kappa_0+n$, $\mu_n = (\kappa_0\mu + n\bar x)/\kappa_n$, $a_n = a+n/2$, $1/b_n = 1/b + \frac12[(n-1)s^2 + \frac{\kappa_0n}{\kappa_n}(\bar x-\mu)^2]$.
(b) Marginally, $\frac{\theta-\mu_n}{\sqrt{1/(\kappa_n a_n b_n)}} \sim t_{2a_n}$; a $1-\alpha$ credible set is $\mu_n \pm t_{2a_n,\alpha/2}\sqrt{1/(\kappa_n a_n b_n)}$.
(c) No. The Bayes set is always $t_{2a_n} = t_{2a+n}$-based with $2a+n > n$, while the classical set is $t_{\,n-1}$-based. In the diffuse limit $\tau^2\to\infty$, $a\to0$, $b\to\infty$: $\mu_n\to\bar x$, $\kappa_n\to n$, $a_n\to n/2$, $1/b_n\to(n-1)s^2/2$, giving $\bar x \pm t_{n,\alpha/2}\frac{s\sqrt{n-1}}{n}$ — close to but not equal to $\bar x \pm t_{n-1,\alpha/2}s/\sqrt n$. (The residual $(\sigma^2)^{-1/2}$ factor in the $n(\mu,\tau^2\sigma^2)$ prior keeps the limiting prior at $(\sigma^2)^{-3/2}$, not Jeffreys' $(\sigma^2)^{-1}$.)
