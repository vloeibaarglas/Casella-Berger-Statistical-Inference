**Central idea.** Each trial gets its own independent $P_i$, so the $X_i$ are iid Bernoulli$(\alpha/(\alpha+\beta))$ — the hierarchy collapses to a plain binomial; (c) is the same computation with $n_i$ trials per group.

**Solution.** The pairs $(X_i,P_i)$ are independent across $i$, so the $X_i$ are iid with $P(X_i=1) = \mathrm{E}[P_i] = \alpha/(\alpha+\beta)$.
(a) $\mathrm{E}Y = n\alpha/(\alpha+\beta)$.
(b) $\mathrm{Var}\,X_i = \mathrm{E}[P_i(1-P_i)]+\mathrm{Var}(P_i) = \frac{\alpha\beta}{(\alpha+\beta)(\alpha+\beta+1)}+\frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)} = \frac{\alpha\beta}{(\alpha+\beta)^2}$, so $\mathrm{Var}\,Y = n\alpha\beta/(\alpha+\beta)^2$. In fact $Y \sim \text{binomial}(n,\alpha/(\alpha+\beta))$ exactly.
(c) $\mathrm{E}Y = \sum_i n_i\mathrm{E}[P_i] = \frac{\alpha}{\alpha+\beta}\sum_i n_i$. The $X_i$ are independent across $i$, so $\mathrm{Var}\,Y = \sum_i\mathrm{Var}\,X_i$ with $\mathrm{Var}\,X_i = \mathrm{E}[n_iP_i(1-P_i)]+\mathrm{Var}(n_iP_i) = n_i\frac{\alpha\beta}{(\alpha+\beta)(\alpha+\beta+1)}+n_i^2\frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)} = n_i\frac{\alpha\beta(\alpha+\beta+n_i)}{(\alpha+\beta)^2(\alpha+\beta+1)}$.
