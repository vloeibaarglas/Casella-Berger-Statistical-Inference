**Central idea.** A bijection of the parameter space transports coverage and false-coverage probabilities unchanged, hence preserves UMA; injectivity is exactly what is needed.

**Solution.** (a) $C^*(x) = \{1/\theta : a(x) \le \theta \le b(x)\}$: if $D^*$ is any $1-\alpha$ set for $\eta = 1/\theta$, then $D = \{1/\eta : \eta \in D^*\}$ is $1-\alpha$ for $\theta$, and $P_\eta(\eta' \in D^*) = P_\theta(\theta' \in D) \ge P_\theta(\theta' \in C) = P_\eta(\eta' \in C^*)$ for $\eta' \ne \eta$ by UMA of $C$. If $a(x) < 0 < b(x)$, $\theta \mapsto 1/\theta$ maps $[a,b]$ to $(-\infty,1/a] \cup [1/b,\infty)$ — neither an interval nor bounded.
(b) $h$ strictly increasing is a bijection: the same transport argument gives UMA of $\{h(\theta) : h(a(X)) \le h(\theta) \le h(b(X))\}$. The condition can be relaxed to $h$ strictly monotone (increasing or decreasing); without injectivity UMA need not be preserved (e.g. $h(\theta) = \theta^2$ folds $\pm\theta$ together, scrambling false-coverage probabilities).
