**Central idea.** Tower laws: $E[Y\mid N] = 2N$, $\mathrm{Var}(Y\mid N) = 4N$; the mgf $M_Y(t) = \exp(\theta\cdot 2t/(1-2t))$ then yields the CLT by the usual mgf expansion.

**Solution.** (a) $EY = E[E[Y\mid N]] = E[2N] = 2\theta$. $\mathrm{Var}\,Y = E[\mathrm{Var}(Y\mid N)] + \mathrm{Var}(E[Y\mid N]) = E[4N] + \mathrm{Var}(2N) = 4\theta + 4\theta = 8\theta$.
(b) $M_Y(t) = E\big[E[e^{tY}\mid N]\big] = E[(1-2t)^{-N}] = E[e^{-N\log(1-2t)}] = \exp\big(\theta(e^{-\log(1-2t)}-1)\big) = \exp\left(\theta\cdot\frac{2t}{1-2t}\right)$, $t < 1/2$. With $s = t/\sqrt{8\theta}$,
$$M_{(Y-2\theta)/\sqrt{8\theta}}(t) = \exp\left(\theta\cdot\frac{2s}{1-2s} - 2\theta s\right) = \exp\left(\frac{4\theta s^2}{1-2s}\right) = \exp\left(\frac{t^2/2}{1-2t/\sqrt{8\theta}}\right) \to e^{t^2/2},$$
the $n(0,1)$ mgf. Hence $(Y-EY)/\sqrt{\mathrm{Var}\,Y} \to_d n(0,1)$.
