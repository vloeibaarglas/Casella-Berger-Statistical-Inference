**Central idea.** As printed this is incorrect — the stated $f_Y$ is not a pdf and $\tan^{-1}$ is not its integral (details below); with the missing $1/\pi$ restored, (a) is a one-line integration and (b) is the inverse-cdf method.

**Solution.** **Erratum (genuine).** As stated, (a) is false, for two independent reasons. First, $f_Y(y) = 1/(1+y^2)$ is not a pdf: $\int_{-\infty}^{\infty}\frac{dy}{1+y^2} = \pi \neq 1$. Second, even formally, $\int_{-\infty}^{y}\frac{dt}{1+t^2} = \tan^{-1}(y) + \frac{\pi}{2} \neq \tan^{-1}(y)$; moreover $\tan^{-1}$ alone cannot be a cdf (its range is $(-\pi/2,\pi/2)$, and $F_Y(-\infty) = -\pi/2 \neq 0$). The intended Cauchy$(0,1)$ pdf is $f_Y(y) = \frac{1}{\pi(1+y^2)}$, for which
$$F_Y(y) = \int_{-\infty}^{y}\frac{dt}{\pi(1+t^2)} = \frac{1}{2} + \frac{1}{\pi}\tan^{-1}(y), \qquad -\infty < y < \infty,$$
which is (a) corrected. For (b): with $U \sim$ uniform$(0,1)$, the inverse-cdf method gives $X = F^{-1}(U)$. Inverting $u = \frac12 + \frac1\pi\tan^{-1}\!\left(\frac{x-a}{b}\right)$ yields
$$X = a + b\tan\!\big(\pi(U-\tfrac12)\big) \sim \text{Cauchy}(a,b),$$
since $P(X \leq x) = P(U \leq \frac12 + \frac1\pi\tan^{-1}(\frac{x-a}{b})) = \frac12 + \frac1\pi\tan^{-1}(\frac{x-a}{b})$, the Cauchy$(a,b)$ cdf.
