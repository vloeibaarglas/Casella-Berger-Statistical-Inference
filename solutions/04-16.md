**Central idea.** The joint pmf of $(U,V)$ factors because the geometric tail is memoryless: $P(U=u,V=v) = p^2(1-p)^{2u+|v|-2}$ splits into a function of $u$ times a function of $v$.

**Solution.** The book's geometric is $P(X=x) = p(1-p)^{x-1}$, $x = 1,2,\dots$ (p. 80), so $X+Y \ge 2$ and the "$Z = 0$ if $X+Y = 0$" clause in (b) is vacuous.
(a) For $u \ge 1$, $v \in \mathbb{Z}$: if $v > 0$, $\{U=u,V=v\} = \{X=u+v,Y=u\}$; if $v < 0$, $\{U=u,V=v\} = \{X=u,Y=u-v\}$; if $v=0$, $\{U=u,V=v\} = \{X=Y=u\}$. In all cases $P(U=u,V=v) = p^2(1-p)^{2u+|v|-2}$. Summing out: $P(U=u) = p^2(1-p)^{2u-2}\left[1+2\sum_{k\ge1}(1-p)^k\right] = p(2-p)(1-p)^{2u-2}$ ($u \ge 1$), and $P(V=v) = p^2(1-p)^{|v|}\sum_{u\ge1}(1-p)^{2u-2} = p(1-p)^{|v|}/(2-p)$ ($v \in \mathbb{Z}$). Their product is $p^2(1-p)^{2u+|v|-2} = P(U=u,V=v)$, so $U,V$ are independent.
(b) Since $Y \ge 1$, $0 < Z = X/(X+Y) < 1$ always. For coprime $0 < s < t$, $\{Z=s/t\} = \bigcup_{k\ge1}\{X=ks,Y=k(t-s)\}$, so $P(Z=s/t) = \sum_{k\ge1}p^2(1-p)^{kt-2} = \frac{p^2(1-p)^{t-2}}{1-(1-p)^t}$.
(c) With $W = X+Y$, $P(X=x,W=w) = P(X=x,Y=w-x) = p^2(1-p)^{w-2}$ for integers $1 \le x \le w-1$ (and $0$ otherwise).
