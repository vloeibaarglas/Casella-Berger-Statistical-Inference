**Central idea.** For a finite family the parameter is just the index, so the ratio criterion (6.2.13) applies verbatim; minimality then lifts to any larger family for which the ratio statistic remains sufficient.

**Solution.** (a) Let the parameter be $i \in \{0,\ldots,k\}$ with density $f_i$. For sample points $\mathbf{x},\mathbf{y}$,
$$\frac{f_i(\mathbf{x})}{f_i(\mathbf{y})} = \frac{f_i(\mathbf{x})/f_0(\mathbf{x})}{f_i(\mathbf{y})/f_0(\mathbf{y})}\cdot\frac{f_0(\mathbf{x})}{f_0(\mathbf{y})},$$
so $\frac{f_i(\mathbf{x})}{f_i(\mathbf{y})}$ is constant in $i$ (including $i = 0$) iff $\frac{f_i(\mathbf{x})/f_0(\mathbf{x})}{f_i(\mathbf{y})/f_0(\mathbf{y})} = 1$ for all $i = 1,\ldots,k$, i.e. iff $T(\mathbf{x}) = T(\mathbf{y})$ where $T(\mathbf{x}) = \big(\frac{f_1(\mathbf{x})}{f_0(\mathbf{x})},\ldots,\frac{f_k(\mathbf{x})}{f_0(\mathbf{x})}\big)$ (common support keeps all ratios defined and positive). By Theorem 6.2.13, $T(\mathbf{X})$ is minimal sufficient for $\{f_0,\ldots,f_k\}$.
(b) Let $T$ be the ratio statistic of (a), now assumed sufficient for $\mathcal{F} \supset \{f_0,\ldots,f_k\}$. If $U$ is any sufficient statistic for $\mathcal{F}$, then $U$ is sufficient for $\{f_0,\ldots,f_k\}$, so by minimality in the finite family $T$ is a function of $U$. Since $U$ was arbitrary, $T$ is minimal sufficient for $\mathcal{F}$.
