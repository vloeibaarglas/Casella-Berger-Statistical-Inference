**Central idea.** Centering the predictor ($z_i = x_i - \bar x$, so $\bar z = 0$) orthogonalizes the design: the slope is unchanged, the intercept collapses to $\bar Y$, and the two estimators become uncorrelated.

**Solution.** (a) In the reparameterized model the predictor is $z_i = x_i - \bar x$. The least squares (hence MLE, under normality) slope is $\hat\beta' = \sum_i z_i(Y_i - \bar Y)/\sum_i z_i^2$. Since $\sum_i z_i^2 = \sum_i(x_i-\bar x)^2 = S_{xx}$ and $\sum_i z_i(Y_i-\bar Y) = \sum_i(x_i-\bar x)(Y_i-\bar Y) = S_{xY}$, $\hat\beta' = S_{xY}/S_{xx} = \hat\beta$.
(b) $\hat\alpha' = \bar Y - \hat\beta'\bar z = \bar Y - \hat\beta'\cdot 0 = \bar Y$. In general $\hat\alpha = \bar Y - \hat\beta\bar x \neq \bar Y$ (they differ unless $\bar x = 0$ or $\hat\beta = 0$), so $\hat\alpha' \neq \hat\alpha$. Since $EY_i = \alpha + \beta x_i = (\alpha + \beta\bar x) + \beta(x_i - \bar x)$, the reparameterized intercept is $\alpha' = \alpha + \beta\bar x$, and $\hat\alpha' = \bar Y \sim n(\alpha',\sigma^2/n) = n(\alpha + \beta\bar x,\sigma^2/n)$.
(c) $\hat\alpha' = \sum_i \frac{1}{n}Y_i$ and $\hat\beta' = \sum_i d_iY_i$ with $d_i = (x_i-\bar x)/S_{xx}$. $\mathrm{Cov}(\hat\alpha',\hat\beta') = \sigma^2\sum_i \frac{1}{n}d_i = \frac{\sigma^2}{nS_{xx}}\sum_i(x_i-\bar x) = 0$. Both are linear in the normal $Y_i$s, hence jointly normal; uncorrelated $\Rightarrow$ independent.
