**Central idea.** Measurement equivariance matches estimates across scales for the same physical data; formal invariance forces one rule for all scales, yielding the location-equivariance equation $T(\mathbf{x}+a) = T(\mathbf{x})+a$.

**Solution.** (a) $\mathbf{y} = g_a(\mathbf{x}) = \mathbf{x}+a$ represents the same physical data in the shifted scale. Estimating $\mu+a$ from $\mathbf{y}$ by $T^*(\mathbf{y})$ and converting back gives the $\mu$-estimate $T^*(\mathbf{y})-a$; measurement equivariance demands this equal the direct estimate $T(\mathbf{x})$.
(b) Formal invariance (the Equivariance Principle) requires the same estimation rule in every scale: $T^*= T$ as functions, i.e. $T(\mathbf{x}) = T^*(\mathbf{x})$ for all $\mathbf{x}$. With (a), $T(\mathbf{x}) = T(\mathbf{x}+a\mathbf{1})-a$, i.e. $T(x_1+a,\ldots,x_n+a) = T(x_1,\ldots,x_n)+a$.
(c) $W(\mathbf{x}+a\mathbf{1}) = \bar{x}+a = W(\mathbf{x})+a$: equivariant. With $X_i = Z_i+\theta$, $\mathrm{E}_\theta W = \mathrm{E}_\theta\bar{X} = \theta + \mathrm{E}_0Z_1 = \theta$.
