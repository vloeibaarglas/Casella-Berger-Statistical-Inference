**Central idea.** Symmetry mirrors the two monotone sides onto each other; a flat density has every point as a mode.

**Solution.** (a) $n(0,1)$, with unique mode 0. (b) uniform$(0,1)$: every $a\in[0,1]$ satisfies the mode inequalities (with equality), so the mode is not unique.
(c) Let $f$ be symmetric about $s$ (Exercise 2.26) and unimodal with mode $m$; assume $m\ge s$ (the case $m<s$ is analogous). Since $m$ is a mode, $f(m)=\max f$, and by symmetry $f(2s-m)=f(m)$, so $2s-m$ is also a mode; note $2s-m\le s\le m$. Because $f$ is nondecreasing on $(-\infty,m]$, every $x\in[2s-m,m]$ satisfies $f(x)\ge f(2s-m)=\max f$, i.e. $f$ is constantly the global maximum on $[2s-m,m]\ni s$. Now check the mode inequalities at $s$: $f(s)=\max f$ dominates every value. For $s\ge x\ge y$: if $x\ge2s-m$ then $f(x)=\max f\ge f(y)$; if $x<2s-m\le m$ then $y\le x$ both lie on $(-\infty,m]$, where $f$ is nondecreasing, so $f(y)\le f(x)$. For $s\le x\le y$: if $x\ge m$ use that $f$ is nonincreasing on $[m,\infty)$; if $x<m$ then $x\in(2s-m,m)$ (since $x\ge s>2s-m$) and $f(x)=\max f\ge f(y)$. Thus $s$ satisfies the mode inequalities: the point of symmetry is a mode.
(d) For $0\le x\le y$: $f(0)=1\ge e^{-x}\ge e^{-y}$; for $x\le0$, $f(x)=0\le f(0)$. Hence unimodal with (unique) mode $a=0$.
