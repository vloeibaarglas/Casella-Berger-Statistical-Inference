**Central idea.** For fixed length, probability mass is maximized by hugging $0$ where the density is highest; hence any $[a,b]$, $a>0$, can be slid left and shrunk.

**Solution.** (a) For fixed length $c$, $\int_0^c f \ge \int_a^{a+c} f$ for all $a \ge 0$ since $f$ is decreasing. Given $[a,b]$ with $\int_a^b f = 1-\alpha$ and $c = b-a$: $\int_0^c f \ge 1-\alpha$, so shrinking to $c' \le c$ with $\int_0^{c'}f = 1-\alpha$ gives a shorter valid interval. Hence $[0,b^*]$, $\int_0^{b^*}f = 1-\alpha$, is shortest.
(b) In 9.2.13 the pivot $Q = n(Y-\mu) \sim \text{Exp}(1)$ has strictly decreasing density $e^{-q}$ on $[0,\infty)$. By (a), the shortest $1-\alpha$ set for $Q$ is $[0,-\log\alpha]$, i.e. $0 \le n(Y-\mu) \le -\log\alpha$: $[Y + (\log\alpha)/n,\ Y]$.
