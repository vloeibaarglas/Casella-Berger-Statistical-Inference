**Central idea.** One-sided hypotheses invert to one-sided bounds (the bound points away from the alternative); the two-sided hypothesis gives the usual $z$-interval.

**Solution.** (a) $A(\theta_0) = \{|\bar x - \theta_0| \le z_{\alpha/2}\sigma/\sqrt{n}\}$; $C = [\bar x - z_{\alpha/2}\sigma/\sqrt{n},\ \bar x + z_{\alpha/2}\sigma/\sqrt{n}]$.
(b) UMP test rejects for small $\bar x$: $A(\theta_0) = \{\bar x \ge \theta_0 - z_\alpha\sigma/\sqrt{n}\}$; $C = (-\infty,\ \bar x + z_\alpha\sigma/\sqrt{n}]$.
(c) UMP test rejects for large $\bar x$: $A(\theta_0) = \{\bar x \le \theta_0 + z_\alpha\sigma/\sqrt{n}\}$; $C = [\bar x - z_\alpha\sigma/\sqrt{n},\ \infty)$.
