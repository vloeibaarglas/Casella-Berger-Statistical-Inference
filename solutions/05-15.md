**Central idea.** Write the new sum of squares about $\bar{X}_{n+1}$ by recentering the old sum of squares (about $\bar{X}_n$) — the cross term vanishes because deviations from $\bar{X}_n$ sum to zero.

**Solution.** (a) Immediate: $\bar{X}_{n+1} = \frac{1}{n+1}\sum_{i=1}^{n+1} X_i = \frac{n\bar{X}_n + X_{n+1}}{n+1}$.
(b) $nS_{n+1}^2 = \sum_{i=1}^{n+1}(X_i - \bar{X}_{n+1})^2$. For $i \leq n$,
$$(X_i - \bar{X}_{n+1})^2 = (X_i - \bar{X}_n)^2 + 2(X_i - \bar{X}_n)(\bar{X}_n - \bar{X}_{n+1}) + (\bar{X}_n - \bar{X}_{n+1})^2,$$
and summing over $i \leq n$ the middle term drops ($\sum_{i \leq n}(X_i - \bar{X}_n) = 0$), giving $(n-1)S_n^2 + n(\bar{X}_n - \bar{X}_{n+1})^2$. Adding $i = n+1$ and using $\bar{X}_{n+1} - \bar{X}_n = \frac{X_{n+1}-\bar{X}_n}{n+1}$ (from (a)):
$$nS_{n+1}^2 = (n-1)S_n^2 + \left[n\cdot\frac{1}{(n+1)^2} + \frac{n^2}{(n+1)^2}\right](X_{n+1}-\bar{X}_n)^2 = (n-1)S_n^2 + \frac{n}{n+1}(X_{n+1}-\bar{X}_n)^2.$$
