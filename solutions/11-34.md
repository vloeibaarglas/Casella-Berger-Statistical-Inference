**Central idea.** $n = 8$: $S_{xx} = 70$, $S_{xy} = 65$, $S_{yy} = 67.5$ give $F = 50.70$; the cross term in $(y_i-\bar y) = (y_i-\hat y_i)+(\hat y_i-\bar y)$ vanishes by the normal equations; $r^2 = S_{xy}^2/(S_{xx}S_{yy})$ is both squared correlations.

**Solution.** (a) $\bar x = 34$, $\bar y = 66.75$, $S_{xx} = 70$, $S_{xy} = 65$, $S_{yy} = 67.5$. $\hat\beta = 65/70 = 0.9286$, $\hat\alpha = 66.75 - 0.9286(34) = 35.179$. $\mathrm{SSR} = S_{xy}^2/S_{xx} = 60.36$, $\mathrm{SSE} = S_{yy} - \mathrm{SSR} = 7.14$.

Height at age two is a strong predictor of adult height ($r^2 = 0.894$).
(b) Write $y_i - \bar y = (y_i - \hat y_i) + (\hat y_i - \bar y)$. Squaring and summing, the cross term is $2\sum_i(y_i-\hat y_i)(\hat y_i-\bar y) = 2\hat\beta\sum_i(y_i-\hat y_i)(x_i-\bar x) = 0$, because $\sum_i(y_i-\hat y_i) = 0$ and $\sum_i x_i(y_i-\hat y_i) = 0$ are the normal equations (and $\hat y_i - \bar y = \hat\beta(x_i-\bar x)$). Hence $\sum_i(y_i-\bar y)^2 = \sum_i(\hat y_i-\bar y)^2 + \sum_i(y_i-\hat y_i)^2$, i.e. (11.3.36): $\mathrm{SST} = \mathrm{SSR} + \mathrm{SSE}$.
(c) $\hat y_i - \bar y = \hat\beta(x_i-\bar x)$, so $\sum_i(\hat y_i-\bar y)^2 = \hat\beta^2S_{xx} = (S_{xy}/S_{xx})^2S_{xx} = S_{xy}^2/S_{xx}$.
(d) $r^2 = \mathrm{SSR}/\mathrm{SST} = S_{xy}^2/(S_{xx}S_{yy}) = \big[S_{xy}/\sqrt{S_{xx}S_{yy}}\big]^2$, the squared sample correlation of the $(y_i,x_i)$ pairs. Also, $\sum_i(y_i-\bar y)(\hat y_i-\bar y) = \hat\beta S_{xy} = S_{xy}^2/S_{xx} = \mathrm{SSR}$ and $\sum_i(\hat y_i-\bar y)^2 = \mathrm{SSR}$ by (c), so the squared sample correlation of the $(y_i,\hat y_i)$ pairs is $\mathrm{SSR}^2/(S_{yy}\cdot\mathrm{SSR}) = \mathrm{SSR}/S_{yy} = r^2$. ✓
