**Central idea.** Direct coefficient matching from $\hat\alpha = \bar{Y} - \hat\beta\bar x$; means, variances and covariances are inner products of the coefficient vectors, simplified with $\sum(x_i-\bar x) = 0$.

**Solution.** (a) $\hat\beta = S_{xY}/S_{xx} = \sum_i d_iY_i$ with $d_i = (x_i-\bar x)/S_{xx}$. $\hat\alpha = \bar{Y} - \bar x\hat\beta = \sum_i(\frac{1}{n} - \bar x d_i)Y_i = \sum_i c_iY_i$ since $\frac{1}{n} - \bar x(x_i-\bar x)/S_{xx} = c_i$.
(b) $E\hat\alpha = \sum_i c_i(\alpha + \beta x_i) = \alpha\sum_ic_i + \beta\sum_ic_ix_i = \alpha$, because $\sum_ic_i = 1$ and $\sum_ic_ix_i = \bar x - \bar x\sum_id_ix_i = \bar x - \bar x = 0$. $\mathrm{Var}\,\hat\alpha = \sigma^2\sum c_i^2$; $\sum c_i^2 = \sum\big[\frac{1}{n^2} - \frac{2\bar x(x_i-\bar x)}{nS_{xx}} + \frac{\bar x^2(x_i-\bar x)^2}{S_{xx}^2}\big] = \frac{1}{n} + \frac{\bar x^2}{S_{xx}} = \frac{S_{xx} + n\bar x^2}{nS_{xx}} = \frac{\sum x_i^2}{nS_{xx}}$ (using $\sum(x_i-\bar x) = 0$, $\sum(x_i-\bar x)^2 = S_{xx}$, $\sum x_i^2 = S_{xx}+n\bar x^2$). Hence $\mathrm{Var}\,\hat\alpha = \sigma^2\sum x_i^2/(nS_{xx})$.
(c) $\mathrm{Cov}(\hat\alpha,\hat\beta) = \sigma^2\sum_i c_id_i = \sigma^2\sum_i\big(\frac{1}{n} - \bar xd_i\big)d_i = \sigma^2\big(\frac{1}{n}\sum_id_i - \bar x\sum_id_i^2\big) = -\sigma^2\bar x/S_{xx}$, using $\sum_id_i = \sum_i(x_i-\bar x)/S_{xx} = 0$ and $\sum_id_i^2 = 1/S_{xx}$.
