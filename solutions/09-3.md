**Central idea.** $X_{(n)}$ is sufficient for $\beta$, and $(X_{(n)}/\beta)^{n\alpha_0} \sim \text{Uniform}(0,1)$ is an exact pivot.

**Solution.** (a) $P_\beta(X_{(n)} \le t) = (t/\beta)^{n\alpha_0}$ for $0 < t < \beta$, so $Q = (X_{(n)}/\beta)^{n\alpha_0} \sim U(0,1)$. Then
$$P_\beta(\beta \le U(X)) = .95 \iff P_\beta(Q \ge .05) = .95 \iff U(x) = \frac{x_{(n)}}{.05^{1/(n\alpha_0)}},$$
a $95\%$ upper confidence limit for $\beta$.
(b) From 7.10, $\hat\beta = x_{(n)} = 25.0$ and $\hat\alpha = n\big/\sum_{i=1}^n \log(x_{(n)}/x_i) = 14/1.1116 = 12.59$ (data: $22.0, 23.9, 20.9, 23.8, 25.0, 24.0, 21.7, 23.8, 22.8, 23.1, 23.1, 23.5, 23.0, 23.0$). The $95\%$ upper limit is $25.0/.05^{1/(14 \times 12.59)} = 25.43$.
