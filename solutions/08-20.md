**Central idea.** The likelihood ratios $6,5,4,3,2,1,0.84$ order the outcomes; the four smallest-$x$ outcomes carry exactly $.04$ of $H_0$ probability, so no randomization is needed.

**Solution.** $r(x) = f(x\mid H_1)/f(x\mid H_0)$: $6, 5, 4, 3, 2, 1, 0.79/.94 \approx 0.84$ for $x=1,\dots,7$. Neyman–Pearson: reject for the largest ratios. $P_{H_0}(X \in \{1,2,3,4\}) = .04$ exactly, so the MP size-$.04$ test is
$$\phi(x) = 1\ \text{if } x \in \{1,2,3,4\},\qquad 0\ \text{otherwise},$$
with no randomization needed ($\alpha$ is attainable). Type II error:
$$P_{H_1}(\text{accept}) = P_{H_1}(X \in \{5,6,7\}) = .02+.01+.79 = .82$$
(power $.18$).
