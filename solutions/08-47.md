**Central idea.** Each one-sided problem is a two-sample $t$-test (as in 8.37(c)); the intersection–union test (TOST) rejects $H_0 = H_0^- \cup H_0^+$ iff both one-sided tests reject, hence level $\alpha$, with the bound sharp as $\sigma \to 0$.

**Solution.** (a) With $\Delta = \mu_X-\mu_Y$, this is $H_0^-: \Delta \le -\delta$ vs $H_1^-: \Delta > -\delta$. Exactly as in 8.37(c) (two-sample version), the LRT rejects for large $\frac{\bar X-\bar Y+\delta}{\sqrt{S_p^2(1/n+1/m)}}$; at $\Delta = -\delta$ this is $t_{n+m-2}$, and for $\Delta < -\delta$ the rejection probability is $< \alpha$ (noncentral $t$ with negative noncentrality): size $\alpha$ LRT.
(b) By symmetry, the size $\alpha$ LRT rejects $H_0^+$ iff $T^+ = \frac{\bar X-\bar Y-\delta}{\sqrt{S_p^2(1/n+1/m)}} \le -t_{n+m-2,\alpha}$.
(c) $H_0 = H_0^- \cup H_0^+$: use the IUT — reject $H_0$ iff both $H_0^-$ and $H_0^+$ are rejected, i.e. iff $T^- \ge t_{n+m-2,\alpha}$ and $T^+ \le -t_{n+m-2,\alpha}$. For $\Delta \in H_0^-$, $P(\text{reject }H_0) \le P(\text{reject }H_0^-) \le \alpha$; similarly on $H_0^+$: level $\alpha$. (The two one-sided tests procedure, TOST.)
(d) At $\Delta = -\delta$, $T^- \sim t_{n+m-2}$ so $P(T^- \ge t_\alpha) = \alpha$, while $T^+ = T^- - \frac{2\delta}{\sqrt{S_p^2(1/n+1/m)}} \to -\infty$ a.s. as $\sigma \to 0$, so $P(T^+ \le -t_\alpha) \to 1$. Hence $P(\text{reject }H_0) = P(T^- \ge t_\alpha, T^+ \le -t_\alpha) \to \alpha$ as $\sigma \to 0$; the level-$\alpha$ bound is best possible, i.e. the test has size $\alpha$.
