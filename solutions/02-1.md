**Central idea.** Each $g$ is strictly monotone on the support, so $f_Y(y) = f_X(g^{-1}(y))\,|dg^{-1}/dy|$; the integral checks are beta integrals in disguise.

**Solution.** (a) $x = y^{1/3}$, $dx/dy = \frac13y^{-2/3}$, $0<y<1$:
$$f_Y(y) = 42y^{5/3}(1-y^{1/3})\cdot\tfrac13y^{-2/3} = 14y(1-y^{1/3}),\quad 0<y<1.$$
$\int_0^1 14y(1-y^{1/3})\,dy = 14\big[\tfrac12-\tfrac37\big] = 1$.
(b) $x = (y-3)/4$, $dx/dy = 1/4$, $y>3$:
$$f_Y(y) = 7e^{-7(y-3)/4}\cdot\tfrac14 = \tfrac74e^{-7(y-3)/4},\quad y>3.$$
With $u = 7(y-3)/4$, $\int_3^\infty f_Y\,dy = \int_0^\infty e^{-u}\,du = 1$.
(c) $x = \sqrt y$, $dx/dy = 1/(2\sqrt y)$, $0<y<1$:
$$f_Y(y) = 30y(1-\sqrt y)^2\cdot\tfrac{1}{2\sqrt y} = 15\sqrt y\,(1-\sqrt y)^2,\quad 0<y<1.$$
With $t=\sqrt y$, $\int_0^1 f_Y\,dy = 30\int_0^1 t^2(1-t)^2\,dt = 30B(3,3) = 30\cdot\frac{2!\,2!}{5!} = 1$.
