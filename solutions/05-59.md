**Central idea.** Accept-reject with a uniform$(0,1)$ candidate: $P(X \leq x, \text{accept}) = \int_0^x f(t)/c\,dt$ and $P(\text{accept}) = 1/c$; the ratio is $\int_0^x f$.

**Solution.** (Example 5.6.7: generate $X \sim$ uniform$(0,1)$, $Y \sim$ uniform$(0,c)$ with $c = \max_{[0,1]} f$, $f$ the beta$(a,b)$ pdf; keep $X$ if $Y < f(X)$.) For $0 \leq x \leq 1$,
$$P(X \leq x,\ Y < f(X)) = \int_0^x P(Y < f(t))\,dt = \int_0^x \frac{f(t)}{c}\,dt,$$
and $P(\text{accept}) = P(Y < f(X)) = \int_0^1 f(t)/c\,dt = 1/c$. Hence
$$P(X \leq x \mid \text{accept}) = \frac{\int_0^x f(t)/c\,dt}{1/c} = \int_0^x f(t)\,dt,$$
so accepted draws have pdf $f$: beta$(a,b)$. (Requires $a, b \geq 1$ so $f$ is bounded on $[0,1]$.)
