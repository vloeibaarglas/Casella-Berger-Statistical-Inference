**Central idea.** Mirror Example 9.2.5: the UMP test rejects for small $X$, and monotonicity of the critical value in $p_0$ (MLR) makes the inverted set an interval $[0, U(x))$.

**Solution.** (a) By MLR and Karlin–Rubin, the UMP level-$\alpha$ test rejects for $X \le k(p_0)$; $A(p_0) = \{X > k(p_0)\}$ (with boundary randomization). $C(x) = \{p_0 : x \in A(p_0)\} = \{p_0 : k(p_0) < x\} = [0, U(x))$ since $k(p_0)$ is nondecreasing in $p_0$, with $U(x) = \sup\{p_0 : k(p_0) < x\}$. Then $P_p(p \in C(X)) = P_p(X \in A(p)) \ge 1-\alpha$.
(b) $U(x)$ solves $P_p(X \le x) = \sum_{y=0}^{x}\binom{n}{y}p^y(1-p)^{n-y} = \alpha$ for $x < n$, with $U(n) = 1$. Compare (9.2.8): the lower bound $L(x)$ instead solves $P_p(X \ge x) = \alpha$ (with $L(0) = 0$).
