**Central idea.** The successive-ratio transformation $W_i = U_i/U_{i+1}$ ($W_n = U_n$) has triangular Jacobian $\prod w_j^{j-1}$, which turns the order-statistic joint pdf into a product of Beta$(ja,1)$-type factors.

**Solution.** $f_{X_{(1)},\ldots,X_{(n)}}(u_1,\ldots,u_n) = n!\left(\frac{a}{\theta^a}\right)^n\prod_{i=1}^{n}u_i^{a-1}$, $0 < u_1 < \cdots < u_n < \theta$. Set $w_i = u_i/u_{i+1}$ ($i < n$), $w_n = u_n$; then $u_i = w_i\cdots w_n$ and $|J| = \prod_{j=1}^{n} w_j^{j-1}$ (upper triangular). Thus
$$f_W(w) = n!\left(\frac{a}{\theta^a}\right)^n\prod_{j=1}^{n} w_j^{j(a-1)}\cdot\prod_{j=1}^{n}w_j^{j-1} = n!\left(\frac{a}{\theta^a}\right)^n\prod_{j=1}^{n} w_j^{ja-1}.$$
This factors over $j$: for $j < n$, $W_j = X_{(j)}/X_{(j+1)}$ has pdf $ja\cdot w^{ja-1}$ on $(0,1)$ (i.e., Beta$(ja,1)$), and $W_n = X_{(n)}$ has pdf $\frac{na}{\theta^{an}}w_n^{na-1}$ on $(0,\theta)$ — indeed $P(X_{(n)} \leq t) = (t^a/\theta^a)^n$. The $n$ variables are mutually independent. (For $a = 1$ this recovers 5.24, with $X_{(1)}/X_{(n)} = \prod_{j=1}^{n-1}W_j \perp X_{(n)}$.)
