**Central idea.** For one-sided bounds unbiasedness is one-sided: an upper bound need only cover false values *above* $\theta$ with probability $\le 1-\alpha$ — which follows from the unbiasedness of the one-sided UMP test it inverts.

**Solution.** For the upper bound $C = (-\infty, \bar X + z_\alpha\sigma/\sqrt n]$, the relevant false values are $\theta' > \theta$: $P_\theta(\theta' \in C) = P_\theta(\bar X \ge \theta' - z_\alpha\sigma/\sqrt n) = 1 - \Phi((\theta'-\theta)/(\sigma/\sqrt n) - z_\alpha) \le 1-\Phi(-z_\alpha) = 1-\alpha$. Similarly the lower bound $[\bar X - z_\alpha\sigma/\sqrt n,\infty)$ satisfies $P_\theta(\theta' \in C) = \Phi((\theta'-\theta)/(\sigma/\sqrt n) + z_\alpha) \le 1-\alpha$ for $\theta' < \theta$. (Equivalently, each inverts a UMP — hence unbiased — one-sided test.)
