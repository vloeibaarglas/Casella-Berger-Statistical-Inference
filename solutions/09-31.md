**Central idea.** Condition on $Y$ to get moments and mgf; the credible set's endpoints, rescaled, sit a factor $nb/(nb+1) < 1$ below where $\chi^2_{2Y}$ concentrates, so the standardized upper limit diverges to $-\infty$.

**Solution.** (a) $E(\chi^2_{2Y}) = E[E(\chi^2_{2Y}\mid Y)] = E(2Y) = 2\lambda$; $\text{Var} = E(4Y) + \text{Var}(2Y) = 4\lambda + 4\lambda = 8\lambda$. $M(t) = E[(1-2t)^{-Y}] = \exp(\lambda((1-2t)^{-1}-1)) = \exp(-\lambda + \lambda/(1-2t))$. For the standardized variable, $\log M(t/\sqrt{8\lambda}) - t\cdot2\lambda/\sqrt{8\lambda} = \lambda(2s + 4s^2 + o(s^2)) - t\sqrt{\lambda/2}$ with $s = t/\sqrt{8\lambda}$, $= t^2/2 + o(1) \to t^2/2$.
(b) (9.2.22): $P(\frac{nb}{nb+1}\chi^2_{2(Y+a),1-\alpha/2} \le \chi^2_{2Y} \le \frac{nb}{nb+1}\chi^2_{2(Y+a),\alpha/2})$, $Y \sim \text{Poisson}(n\lambda)$. Standardizing $\chi^2_{2Y}$, the upper limit becomes
$$\frac{\frac{nb}{nb+1}\chi^2_{2(Y+a),\alpha/2} - 2\lambda}{\sqrt{8\lambda}} = \frac{-\frac{2\lambda}{nb+1} + O_p(\sqrt{\lambda})}{\sqrt{8\lambda}} \to -\infty,$$
since $\chi^2_{2(Y+a),\alpha/2} = 2(Y+a) + O_p(\sqrt{Y})$ and $Y/(n\lambda) \xrightarrow{p} 1$. Hence the coverage probability $\to P(Z \le -\infty) = 0$.
