**Central idea.** For $\theta \in \Theta_{j_0}$, $\max_j p_j \ge p_{j_0}$, so $\{p \le \alpha\} \subseteq \{p_{j_0} \le \alpha\}$; and $p(\mathbf x) \le \alpha$ iff every $p_j(\mathbf x) \le \alpha$.

**Solution.** (a) A p-value is valid if $P_\theta(p(\mathbf X) \le \alpha) \le \alpha$ for $\theta \in \Theta_0$. If $\theta \in \bigcup_j \Theta_j$, then $\theta \in \Theta_{j_0}$ for some $j_0$, and $p(\mathbf X) = \max_j p_j(\mathbf X) \ge p_{j_0}(\mathbf X)$. Hence $\{p(\mathbf X) \le \alpha\} \subseteq \{p_{j_0}(\mathbf X) \le \alpha\}$, so $P_\theta(p(\mathbf X) \le \alpha) \le P_\theta(p_{j_0}(\mathbf X) \le \alpha) \le \alpha$ (validity of $p_{j_0}$ on $\Theta_{j_0}$). Thus $p$ is valid for $H_0$.
(b) Reject $H_0$ at level $\alpha$ iff $p(\mathbf x) \le \alpha$ iff $\max_j p_j(\mathbf x) \le \alpha$ iff $p_j(\mathbf x) \le \alpha$ for every $j$ iff each $H_{0j}$ is rejected at level $\alpha$: exactly the IUT for $H_0 = \bigcup_j \Theta_j$.
