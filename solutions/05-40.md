**Central idea.** Convergence in probability implies convergence in distribution: sandwich $\{X_n \leq t\}$ between $\{X \leq t \pm \varepsilon\}$ up to the vanishing event $\{|X_n - X| \geq \varepsilon\}$, then let $\varepsilon \to 0$ through continuity points.

**Solution.** (a) $\{X \leq t-\varepsilon\} \subseteq \{X_n \leq t\} \cup \{|X_n - X| \geq \varepsilon\}$: if $X \leq t-\varepsilon$ but $|X_n-X| < \varepsilon$, then $X_n < X + \varepsilon \leq t$. Taking probabilities and rearranging, $P(X_n \leq t) \geq P(X \leq t-\varepsilon) - P(|X_n-X| \geq \varepsilon)$.
(b) Similarly $\{X_n \leq t\} \subseteq \{X \leq t+\varepsilon\} \cup \{|X_n-X| \geq \varepsilon\}$, so $P(X_n \leq t) \leq P(X \leq t+\varepsilon) + P(|X_n-X| \geq \varepsilon)$.
(c) With $X_n \to_p X$, $P(|X_n-X| \geq \varepsilon) \to 0$; hence $\liminf P(X_n \leq t) \geq P(X \leq t-\varepsilon)$ and $\limsup P(X_n \leq t) \leq P(X \leq t+\varepsilon)$ for every $\varepsilon > 0$. For continuous $X$ every $t$ is a continuity point of $F_X$, so letting $\varepsilon \to 0$ pinches: $P(X_n \leq t) \to P(X \leq t)$.
