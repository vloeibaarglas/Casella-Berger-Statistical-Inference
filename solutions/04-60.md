**Central idea.** This is the Borel paradox: conditioning on the probability-zero set $\{Y=X\}$ is ambiguous — approaching it via the difference $Y-X$, via the ratio $Y/X$, or via the indicator $I(Y=X)$ gives different (or undefined) answers.

**Solution.** Let $X,Y$ be iid $n(0,1)$.
(1) $Z_1 = Y-X = 0$: $(X,Z_1)$ is bivariate normal with $\mathrm{Cov}(X,Z_1) = -1$, $\mathrm{Var}\,Z_1 = 2$, so $X|Z_1=0 \sim n(0,1/2)$; on $\{Z_1=0\}$, $Y=X$, hence $Y|Z_1=0 \sim n(0,1/2)$.
(2) $Z_2 = Y/X = 1$: with $y = xz$, $|J| = |x|$, $f_{X,Z_2}(x,1) = |x|\frac{1}{2\pi}e^{-x^2}$ and $f_{Z_2}(1) = 1/(2\pi)$, so $f_{X|Z_2=1}(x) = |x|e^{-x^2}$; on $\{Z_2=1\}$ (minus a null set) $Y=X$, so $Y|Z_2=1$ has pdf $f(y) = |y|e^{-y^2}$, $y\in\mathbb{R}$ — different from (1).
(3) $Z_3 = I(Y=X) = 1$: $P(Z_3=1) = P(Y=X) = 0$, and the indicator specifies no direction of approach, so there is no canonical conditional distribution — conditioning here is undefined (any version is valid). The three "correct" interpretations disagree: the Borel paradox.
