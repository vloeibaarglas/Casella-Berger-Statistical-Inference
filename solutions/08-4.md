**Central idea.** For a discrete model the pmf value $f(\mathbf x \mid \theta)$ literally is $P_\theta(\mathbf X = \mathbf x)$, so each supremum in $\lambda$ is a maximum probability of the observed sample.

**Solution.** By Definition 8.2.1,
$$\lambda(\mathbf x) = \frac{\sup_{\theta \in \Theta_0} L(\theta \mid \mathbf x)}{\sup_{\theta \in \Theta} L(\theta \mid \mathbf x)}, \qquad L(\theta \mid \mathbf x) = f(\mathbf x \mid \theta).$$
If $f(\cdot \mid \theta)$ is a pmf, then $f(\mathbf x \mid \theta) = P_\theta(\mathbf X = \mathbf x)$, the probability of the observed sample under $\theta$. Hence $\sup_{\Theta_0} L$ is the largest probability assignable to the observed sample by any null parameter value, and $\sup_\Theta L$ is the largest probability assignable by any parameter value at all. The ratio $\lambda(\mathbf x)$ therefore compares the best null explanation of the data against the best overall explanation.
