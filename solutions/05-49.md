**Central idea.** Inverse-cdf method throughout: $-\log U$ inverts the exponential cdf, $\log\frac{u}{1-u}$ inverts the logistic cdf $e^x/(1+e^x)$, and location-scale does the rest.

**Solution.** (a) $P(-\log U \leq x) = P(U \geq e^{-x}) = 1-e^{-x}$ ($x \geq 0$); $1-U \stackrel{d}{=} U$, so $-\log(1-U)$ is exponential$(1)$ too.
(b) $P(X \leq x) = P\left(\frac{U}{1-U} \leq e^x\right) = P\left(U \leq \frac{e^x}{1+e^x}\right) = \frac{e^x}{1+e^x} = \frac{1}{1+e^{-x}}$, the logistic$(0,1)$ cdf.
(c) If $Z \sim \text{logistic}(0,1)$, then $X = \mu + \beta Z$ has cdf $1/(1+e^{-(x-\mu)/\beta})$, i.e., logistic$(\mu,\beta)$. So generate $U \sim$ uniform$(0,1)$ and return $X = \mu + \beta\log\frac{U}{1-U}$.
