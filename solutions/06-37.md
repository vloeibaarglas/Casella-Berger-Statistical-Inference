**Central idea.** $X\sim\text{Exp}(\theta)\perp Y\sim\text{Exp}(1/\theta)$; $(T,U)$ is 1–1 with $(\sum X_i,\sum Y_i)$ (preserving information and sufficiency), while $T = \theta\sqrt{A/B}$ is a scale statistic whose information is computed via the $\text{Beta}(n,n)$ law of $A/(A+B)$.

**Solution.** (a) $f$ factors as $\theta e^{-\theta x}\cdot\frac{1}{\theta}e^{-y/\theta}$: $X\sim\text{exponential}(\theta)\perp Y\sim\text{exponential}(1/\theta)$. $\frac{\partial^2}{\partial\theta^2}\log f = -\frac{2y}{\theta^3}$, so $I_1(\theta) = \frac{2\mathrm{E}_\theta Y}{\theta^3} = \frac{2\theta}{\theta^3} = \frac{2}{\theta^2}$; for $n$ iid pairs, $I(\theta) = 2n/\theta^2$.
(b) Note $(\sum X_i,\sum Y_i)\leftrightarrow(T,U)$ is 1–1 on $(0,\infty)^2$: $\sum X_i = U/T$, $\sum Y_i = UT$.
(ii) $(\sum X_i,\sum Y_i)$ is sufficient (two-parameter exponential family), and 1–1 transformations preserve Fisher information, so $I_{(T,U)}(\theta) = I(\theta) = 2n/\theta^2$.
(i) $T^2 = \frac{\sum Y_i}{\sum X_i} = \theta^2\frac{A}{B}$ with $A = \frac{1}{\theta}\sum Y_i$, $B = \theta\sum X_i$ iid $\text{Gamma}(n,1)$. From $f_{T,U}(t,u) = \frac{2}{\Gamma(n)^2}u^{2n-1}t^{-1}e^{-u(\theta/t+t/\theta)}$ (Jacobian $2u/t$), $f_T(t) \propto \theta^{2n}t^{2n-1}/(\theta^2+t^2)^{2n}$, giving score $\frac{2n(T^2-\theta^2)}{\theta(T^2+\theta^2)}$. Hence $I_T(\theta) = \frac{4n^2}{\theta^2}\mathrm{E}\big[\frac{(V-1)^2}{(V+1)^2}\big]$ with $V = T^2/\theta^2 = A/B$. Since $\frac{V-1}{V+1} = \frac{A-B}{A+B} = 2P-1$ with $P = \frac{A}{A+B}\sim\text{Beta}(n,n)$, $\mathrm{E}\big[\frac{(V-1)^2}{(V+1)^2}\big] = 4\mathrm{Var}(P) = \frac{1}{2n+1}$. Thus $I_T(\theta) = \frac{4n^2}{(2n+1)\theta^2} = \frac{2n}{2n+1}I(\theta)$.
(iii) $(T,U)$ is a 1–1 function of the sufficient $(\sum X_i,\sum Y_i)$, hence sufficient. Not complete: $\mathrm{E}_\theta[U^2] = \mathrm{E}_\theta[\sum X_i]\,\mathrm{E}_\theta[\sum Y_i] = \frac{n}{\theta}\cdot n\theta = n^2$ for all $\theta$, so $U^2-n^2$ is a nonzero unbiased estimator of $0$.
