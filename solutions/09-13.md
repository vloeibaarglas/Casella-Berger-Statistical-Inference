**Central idea.** The definition is $Y=-1/\log X$, the reciprocal of $-\log X$. Consequently $F_Y(y)=e^{-\theta/y}$ for $y>0$, and $\theta/Y=-\theta\log X\sim\mathrm{Exp}(1)$ is a pivot.

**Solution.** (a) For $y>0$, $P(Y\le y)=P(X\le e^{-1/y})=e^{-\theta/y}$. Hence
$$P_\theta(\theta\in[Y/2,Y])=P_\theta(\theta\le Y\le2\theta)=e^{-1/2}-e^{-1}=:c_0=0.2386512185.$$
This is constant in $\theta$, so it is also the confidence coefficient.

(b) With $Q=\theta/Y\sim\mathrm{Exp}(1)$, any fixed $0\le a<b$ satisfying $e^{-a}-e^{-b}=c_0$ gives the exact confidence set $[aY,bY]\cap(0,\infty)$. Equivalently, $X^\theta\sim U(0,1)$: endpoints $0<A<B\le1$ with $B-A=c_0$ give $[\log B/\log X,\log A/\log X]\cap(0,\infty)$.

(c) The original interval corresponds to $(a,b)=(1/2,1)$. Among intervals obtained from **fixed endpoints of this pivot**, length is $(b-a)Y$. Since $b=-\log(e^{-a}-c_0)$,
$$\frac{d}{da}(b-a)=\frac{c_0}{e^{-a}-c_0}>0.$$
Thus the shortest interval in this class takes $a=0$ and $b=-\log(1-c_0)=0.2726637062$:
$$C(Y)=(0,\,-Y\log(1-c_0)].$$
It has exactly the same confidence coefficient and is shorter for every $Y>0$ than $[Y/2,Y]$. The decimal $.239$ is only a rounding of $c_0$; use $c_0$, not the rounded decimal, to preserve the exact coefficient. This comparison does not assert optimality among all possible confidence procedures.
