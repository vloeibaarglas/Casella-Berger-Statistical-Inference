**Central idea.** Conditioning on the observed $\sigma$, test (a) is sensible; test (b) gains unconditional power by always rejecting when $\sigma = 10$ — but its inverted "confidence set" is empty whenever $\sigma = 10$ is observed.

**Solution.** (a) Conditionally on $\sigma$, $P_{\theta_0}(X > \theta_0+z_\alpha\sigma\mid\sigma) = \alpha$, so unconditionally level $\alpha$. $A(\theta_0) = \{X \le \theta_0+z_\alpha\sigma\}$; $C(x,\sigma) = \{\theta_0 : \theta_0 \ge x - z_\alpha\sigma\} = [x-z_\alpha\sigma,\infty)$, a $1-\alpha$ lower bound using the *observed* $\sigma$.
**Audit note.** The exercise asks to "show that" test (b) is more powerful, but the power comparison is invalid: because $(\alpha-p)/(1-p) < \alpha$, the cutoff $z_{(\alpha-p)/(1-p)}$ is *larger* than $z_\alpha$, not smaller. Numerically ($\alpha=.1$, $p=.05$), test (a) has the higher power for small shifts ($\delta=.25$: $.149$ vs $.131$; $\delta=1$: $.376$ vs $.304$; $\delta=2$: $.733$ vs $.666$) while test (b) wins only for large shifts ($\delta=3$: $.917$ vs $.920$; $\delta=5$: $.961$ vs $1.000$) — the powers cross, so neither test uniformly dominates. The level calculation and the empty-set inversion below are correct.

(b) Level: $p\cdot1 + (1-p)P_{\theta_0}(X > \theta_0+z_{(\alpha-p)/(1-p)}\mid\sigma=1) = p + (\alpha-p) = \alpha$. Inverting: $A(\theta_0) = \{\sigma=1,\ X \le \theta_0+z_{(\alpha-p)/(1-p)}\}$, so $C = [x-z_{(\alpha-p)/(1-p)},\infty)$ if $\sigma=1$ and $C = \varnothing$ if $\sigma=10$ — empty with probability $p > 0$, yet $P_\theta(\theta\in C) = (1-p)(1-\frac{\alpha-p}{1-p}) = 1-\alpha$.
