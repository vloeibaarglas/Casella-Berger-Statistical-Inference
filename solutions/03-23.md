**Central idea.** Power integrals $\int_\alpha^\infty x^{-k}dx$; moments exist only when the exponent beats 1.

**Solution.** (a) $\int_\alpha^\infty\frac{\beta\alpha^\beta}{x^{\beta+1}}dx = \beta\alpha^\beta\left[\frac{x^{-\beta}}{-\beta}\right]_\alpha^\infty = 1$. (b) $EX = \beta\alpha^\beta\int_\alpha^\infty x^{-\beta}dx = \frac{\beta\alpha}{\beta-1}$ ($\beta>1$); $EX^2 = \frac{\beta\alpha^2}{\beta-2}$ ($\beta>2$); Var$X = \frac{\beta\alpha^2}{\beta-2}-\frac{\beta^2\alpha^2}{(\beta-1)^2} = \frac{\beta\alpha^2}{(\beta-1)^2(\beta-2)}$ ($\beta>2$). (c) For $\beta\le2$, $EX^2 = \int_\alpha^\infty\beta\alpha^\beta x^{1-\beta}dx = \infty$ (since $1-\beta\ge-1$), so the variance does not exist (it is infinite).
