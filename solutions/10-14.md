**Central idea.** The nonparametric bootstrap resamples the data (model-free but limited to the empirical distribution); the parametric bootstrap simulates from the fitted model (smooth, but inherits model risk).

**Solution.** (a) For $-1.81,0.63,2.22,2.41,2.95,4.16,4.24,4.53,5.09$ ($S^2=4.82$), resampling $n=9$ values with replacement ($B=20000$) and computing $S^{2*}$ each time gives $\mathrm{Var}^*_B(S^2)\approx 4.46$, close to the book's parametric bootstrap $4.33$ (and below the normal-theory $5.81$). The nonparametric version assumes nothing about normality — an advantage when the model is doubtful — but is jerkier for small $n$.
(b) For the anchovy counts $19,32,\ldots,23$ ($n=13$, $\bar x=18.69$, $S^2=44.90$), the nonparametric bootstrap distribution of $S^{2*}$ has mean $\approx 41.4$ and sd $\approx 15.7$, versus the Poisson parametric bootstrap's mean $18.86$, sd $7.68$ (Figure 5.6.2). The data are strongly overdispersed ($S^2\gg\bar x$), which the nonparametric bootstrap honestly reflects while the Poisson parametric bootstrap suppresses — a clear win for the nonparametric approach when the model is wrong; its disadvantage is coarseness from only $n=13$ distinct values.
(c) MLEs: $\hat\mu=\bar x=2.303$; solving $\psi(\alpha)-\log\alpha=\overline{\log x}-\log\bar x$ gives $\hat\alpha=1.215$, $\hat\beta=\bar x/\hat\alpha=1.896$, so $\widehat{\mathrm{Var}}=\hat\alpha\hat\beta^2=4.367$. A parametric bootstrap ($B=4000$ from gamma$(\hat\alpha,\hat\beta)$, refitting each time) gives SE$(\hat\mu)\approx 0.83$ and SE$(\widehat{\mathrm{Var}})\approx 4.35$ — the variance estimate is very noisy, as expected with $n=6$.
