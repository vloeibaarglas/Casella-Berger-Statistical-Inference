**Central idea.** The induced law $P_X(B) = P(X^{-1}(B))$ inherits everything from $P$ because preimages preserve set operations (unions, disjointness).

**Solution.** Recall (1.4.1): $P_X(X = x_i) = P(\{s_j \in S : X(s_j) = x_i\})$, i.e., $P_X(B) = P(X^{-1}(B))$. Nonnegativity is inherited. $P_X(\mathbb{R}) = P(X^{-1}(\mathbb{R})) = P(S) = 1$. If $B_i$ are disjoint, so are $X^{-1}(B_i)$ (a point can't map into two disjoint sets), and $X^{-1}(\cup_i B_i) = \cup_i X^{-1}(B_i)$; hence $P_X(\cup_i B_i) = P(\cup_i X^{-1}(B_i)) = \sum_i P(X^{-1}(B_i)) = \sum_i P_X(B_i)$.
