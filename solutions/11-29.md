**Central idea.** Bilinearity of covariance gives the six-term decomposition in (b); Lemma 11.3.2 reduces each covariance to a coefficient ($c_i$ or $d_i$) times $\sigma^2$ — and the text's $+$ sign in the first covariance is a typo for $-$, without which (11.3.28) does not follow.

**Solution.** (a) $E\hat\alpha = \alpha$, $E\hat\beta = \beta$, so $E\hat\varepsilon_i = (\alpha+\beta x_i) - \alpha - \beta x_i = 0$.
(b) Write $\hat\varepsilon_i = Y_i + (-\hat\alpha) + (-x_i\hat\beta)$ and expand by bilinearity:
$$\mathrm{Var}\,\hat\varepsilon_i = \mathrm{Var}\,Y_i + \mathrm{Var}\,\hat\alpha + x_i^2\,\mathrm{Var}\,\hat\beta + 2\,\mathrm{Cov}(Y_i,-\hat\alpha) + 2\,\mathrm{Cov}(Y_i,-x_i\hat\beta) + 2\,\mathrm{Cov}(-\hat\alpha,-x_i\hat\beta),$$
which is the stated formula, since $\mathrm{Cov}(-\hat\alpha,-x_i\hat\beta) = x_i\,\mathrm{Cov}(\hat\alpha,\hat\beta)$.
(c) By Lemma 11.3.2, $\mathrm{Cov}(Y_i,\hat\alpha) = c_i\sigma^2$ and $\mathrm{Cov}(Y_i,\hat\beta) = d_i\sigma^2$, with $c_i = \frac{1}{n} - \frac{(x_i-\bar x)\bar x}{S_{xx}}$ and $d_i = \frac{x_i-\bar x}{S_{xx}}$ from 11.30(a).
*Erratum:* the text prints the first covariance with a $+$ sign, $\sigma^2\big(\frac{1}{n} + \frac{(x_i-\bar x)\bar x}{S_{xx}}\big)$ — this is wrong; the correct sign is $-$. Proof: (i) Lemma 11.3.2 gives $\mathrm{Cov}(Y_i,\hat\alpha) = c_i\sigma^2$, and 11.30(a) — the very next exercise, with the same estimators — prints $c_i = \frac{1}{n} - \frac{(x_i-\bar x)\bar x}{S_{xx}}$, so the text contradicts itself; (ii) only the minus sign reproduces (11.3.28): with the $+$ sign the computation below misses by $-4\bar x(x_i-\bar x)/S_{xx}$ (checked numerically — the $+$ version even produces negative "variances").
Using the corrected covariances, with $\mathrm{Var}\,Y_i = \sigma^2$, $\mathrm{Var}\,\hat\alpha = \sigma^2\sum_jx_j^2/(nS_{xx})$, $\mathrm{Var}\,\hat\beta = \sigma^2/S_{xx}$ and $\mathrm{Cov}(\hat\alpha,\hat\beta) = -\sigma^2\bar x/S_{xx}$ (all from 11.30), part (b) gives
$$\frac{\mathrm{Var}\,\hat\varepsilon_i}{\sigma^2} = 1 - \frac{2}{n} + \frac{1}{S_{xx}}\left[\frac{1}{n}\sum_{j=1}^n x_j^2 + x_i^2 + 2\bar x(x_i-\bar x) - 2x_i(x_i-\bar x) - 2x_i\bar x\right].$$
Since $2\bar x(x_i-\bar x) - 2x_i(x_i-\bar x) = -2(x_i-\bar x)^2$, the bracket equals $\frac{1}{n}\sum_jx_j^2 + x_i^2 - 2(x_i-\bar x)^2 - 2x_i\bar x$, and $1 - 2/n = (n-2)/n$: exactly (11.3.28). Equivalently, after simplifying with $n^{-1}\sum_jx_j^2=S_{xx}/n+\bar x^2$, the familiar result is $\operatorname{Var}(\hat\varepsilon_i)=\sigma^2[1-1/n-(x_i-\bar x)^2/S_{xx}]$.
