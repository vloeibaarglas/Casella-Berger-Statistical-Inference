**Central idea.** The population regression slope is $\beta = \rho\sigma_Y/\sigma_X$, so $\beta = 0 \iff \rho = 0$; the usual $t$ statistic for the slope rewrites as a function of $r$ alone.

**Solution.** (a) From (11.3.25), the conditional distribution of $Y$ given $X = x$ in the bivariate normal model is $n(\alpha + \beta x,\sigma^2)$ with $\beta = \rho\,\sigma_Y/\sigma_X$. Since $\sigma_X,\sigma_Y > 0$, $\beta = 0 \iff \rho = 0$.
(b) $\hat\beta = S_{xy}/S_{xx}$ and $r = S_{xy}/\sqrt{S_{xx}S_{yy}}$, so $\hat\beta = r\sqrt{S_{yy}/S_{xx}}$. With $S^2 = \mathrm{SSE}/(n-2)$ and $\mathrm{SSE} = S_{yy} - S_{xy}^2/S_{xx} = S_{yy}(1-r^2)$:
$$\frac{\hat\beta}{S/\sqrt{S_{xx}}} = \frac{r\sqrt{S_{yy}}}{\sqrt{S_{yy}(1-r^2)/(n-2)}} = \sqrt{n-2}\,\frac{r}{\sqrt{1-r^2}}.$$
(c) Under $H_0:\rho = 0$ (equivalently $H_0:\beta = 0$), the statistic $T = r\sqrt{n-2}/\sqrt{1-r^2}$ is exactly the $t$ statistic for $H_0:\beta = 0$, so $T \sim t_{n-2}$. Reject $H_0:\rho = 0$ at level $\alpha$ if $|T| > t_{n-2,\alpha/2}$; computing $|T| = \sqrt{n-2}\cdot\sqrt{r^2/(1-r^2)}$ needs only $r^2$ and $n$.
