**Central idea.** The pivot $n(Y-\mu) \sim \text{Exp}(1)$ has a strictly decreasing density, so the shortest pivotal interval hugs $0$ — and the LRT reproduces exactly this interval.

**Solution.** Pivotal/shortest: $Q = n(Y-\mu) \sim \text{Exp}(1)$; by 9.41 the shortest $1-\alpha$ set for $Q$ is $[0,-\log\alpha]$, giving $\mu \in [Y + (\log\alpha)/n,\ Y]$, length $-(\log\alpha)/n$. LRT: $\lambda = e^{-n(Y-\mu_0)}I(\mu_0 \le Y)$; $-2\log\lambda = 2n(Y-\mu_0) \sim \chi^2_2$ exactly, so the $1-\alpha$ LRT interval is $[Y - \chi^2_{2,\alpha}/(2n),\ Y] = [Y + (\log\alpha)/n,\ Y]$ — identical to the shortest pivotal interval (since $\chi^2_{2,\alpha} = -2\log\alpha$). Example 9.2.13's equal-tail cdf interval is $[Y + \log(\alpha/2)/n,\ Y + \log(1-\alpha/2)/n]$, strictly longer (e.g. $\alpha=.1$: $2.94/n$ vs $2.30/n$).
