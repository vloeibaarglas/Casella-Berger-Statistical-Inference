**Central idea.** (a) follows by applying Exercise 2.10 to $-T$. *Erratum:* the set in (b) as printed is empty — the inequalities must be reversed, after which Bonferroni on the stochastic-dominance bounds gives $1-\alpha$.

**Solution.** (a) $\bar F_T(T\mid\theta) = P(T \ge T\mid\theta) = P(-T \le -T\mid\theta) = F_{-T}(-T\mid\theta)$; Exercise 2.10 applied to $-T$ gives $P_\theta(\bar F_T(T\mid\theta) \le x) \le x$.
(b) *Erratum — as stated this is false.* Take $Y \sim \text{Poisson}(10\lambda)$, $y = 6$, $\alpha_1 = \alpha_2 = .05$: $\{F_Y(6\mid\lambda) \le .05\} = \{\lambda \ge 1.184\}$ (since $P(Y\le6\mid\lambda)$ decreases in $\lambda$) and $\{\bar F_Y(6\mid\lambda) \le .05\} = \{\lambda \le .261\}$; the intersection is $\varnothing$, not a $1-\alpha$ set. The correct set reverses the inequalities: $C = \{\theta : F_T(T\mid\theta) \ge \alpha_1 \text{ and } \bar F_T(T\mid\theta) \ge \alpha_2\}$ (this matches the continuous case 9.2.12, where $\bar F = 1-F$). Then
$$P_\theta(\theta \notin C) \le P_\theta(F_T(T\mid\theta) < \alpha_1) + P_\theta(\bar F_T(T\mid\theta) < \alpha_2) \le \alpha_1 + \alpha_2 = \alpha$$
by (a). In case (i) ($F_T$ decreasing in $\theta$), $\{F_T(t\mid\theta) \ge \alpha_1\} = (-\infty,\theta_U(t)]$ and $\{\bar F_T(t\mid\theta) \ge \alpha_2\} = [\theta_L(t),\infty)$ by (c), so $C = [\theta_L(T),\theta_U(T)]$.
(c) $\bar F_T(t\mid\theta) = 1 - \lim_{s\uparrow t}F_T(s\mid\theta)$; each $F_T(s\mid\cdot)$ decreasing implies $\bar F_T(t\mid\cdot)$ nondecreasing.
(d) Case (ii): $F_T$ increasing in $\theta$, so $\bar F_T$ decreasing. With $\bar F_T(t\mid\theta_U) = \alpha_1$, $F_T(t\mid\theta_L) = \alpha_2$: the corrected set $\{\theta : F_T(T\mid\theta) \ge \alpha_2,\ \bar F_T(T\mid\theta) \ge \alpha_1\} = [\theta_L(T),\theta_U(T)]$ is a $1-\alpha$ interval by the Bonferroni argument in (b).
