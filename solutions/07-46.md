**Central idea.** $E_\theta X_1=3\theta/2$ gives the MOM; the likelihood $L\propto\theta^{-3}$ on $[X_{(3)}/2,X_{(1)}]$ is maximized at the left endpoint; Rao–Blackwell improves only the non-sufficient MOM estimator.
**Solution.** (a) $E_\theta X_1=3\theta/2$, so $\tilde\theta=2\bar X/3$.
(b) $L(\theta\mid\mathbf{x})=\theta^{-3}\mathbf{1}_{[x_{(3)}/2\le\theta\le x_{(1)}]}$, strictly decreasing in $\theta$ on the feasible interval, so $\hat\theta=X_{(3)}/2$. Since $E_\theta X_{(3)}=2\theta-\theta/4=7\theta/4$, $E_\theta\hat\theta=7\theta/8$; thus $k=8/7$ makes $(8/7)\hat\theta$ unbiased.
(c) $(X_{(1)},X_{(3)})$ is sufficient. The MOM $\tilde\theta=2\bar X/3$ is not a function of it, so $E[\tilde\theta\mid X_{(1)},X_{(3)}]$ is a strictly better (Rao–Blackwell) unbiased estimator. The MLE $\hat\theta=X_{(3)}/2$ is already a function of the sufficient statistic, so sufficiency cannot improve it.
(d) $\bar x=1.16$: MOM $\tilde\theta=2(1.16)/3\approx 0.773$; MLE $\hat\theta=1.33/2=0.665$ (feasible since $x_{(1)}=0.86\ge0.665$).
